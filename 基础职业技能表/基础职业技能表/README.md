## 覆盖源文件前的正确流程

1. 先备份：把将被覆盖的现有文件复制到 `备份区/<年月>/<批次>更新前/`。
2. 逐文件体检：`python -X utf8 scripts/check_source_replacement.py <新文件> <目标文件>`
   —— 若报"疑似残缺版本"，**停下并人工确认**，不要加 `--force` 硬盖。
3. 覆盖后校验 SHA1 一致，并同步 `基础职业技能表/基础职业技能表/` 下的副本，避免两套源漂移。
