# Windows 桌面稳定性修复与验收记录

2026 年 10 月 3 日。工作区：D:/Download/scholar-agent-main，基线提交 3ab1a0d，应用版本仍为 1.0.8039。代码、本机测试和本地安装产物验收已完成，尚未发布。

本轮处理 Windows 桌面启动崩溃与白屏的恢复、诊断和数据保护问题。玩家现场首次启动闪退的具体触发原因没有复现，不能将本轮验收解释为所有机器的闪退都已消除。保留了此前的技能完整性、上传页及角色字段修复。

## 已落地的行为

- 取得单实例锁后才初始化窗口和服务。重复启动唤起已有主窗口；主窗口关闭、预览仍在时再次启动会复建主窗口。CLI 服务保持一个，并通过函数读取当前主窗口。
- 主进程、渲染进程和 GPU 退出分别记录。日志放在用户目录 diagnostics，默认最多五份、每份五 MiB，目录不可写时尝试临时目录。日志仅记录受限元信息和脱敏页面路径，不记录错误消息正文、完整角色、恢复草稿或 API 密钥。导出不包含草稿和原生 dump。
- 顾问配置读取异常、CLI 连接文件异常、隐藏页面任务超时按功能降级。CLI 单次页面任务上限二十秒，失败销毁临时窗口并释放队列；写入任务不自动重试。
- 主窗口和真实 window.open 子窗口统一注册加载与恢复处理。主框架加载失败、必要脚本缺失和可用性失败进入独立错误页；支持重试、回启动台、诊断导出和兼容渲染。导航换代与 ERR_ABORTED 不触发旧页面恢复。
- 只读预览最多两扇，限流不占用编辑或 CLI 窗口。内部预览允许在主窗口关闭后继续存在。
- 渲染崩溃最多自动恢复两次每分钟，第三次进入错误页。编辑页先检查独立草稿。六秒持续无响应会提供等待与明确恢复的选择，页面恢复响应后取消重载；不再无条件丢掉编辑状态。
- 正在编辑的页面若加载未完成，停止待完成请求并保留当前改动，提示先保存。崩溃后的错误路径仍可进入故障页。
- 版本变化时才清理可重建 HTTP 缓存，等待有上限。Local Storage、角色库、原始工作簿缓存和恢复草稿不清理。

## 独立恢复草稿

recovery-store.js 保存到 userData/recovery-drafts，与正式角色存档分开。格式版本为 1，按模块、角色存储标识和槽位定位；每个标识保存最近一次完整快照。序号文件独立保留，清理草稿后不重用旧序号。

快照通过临时文件、fsync 和原子替换写入，完成后返回 ACK。单份上限十六 MiB，总量一百二十八 MiB。超限、损坏或未知版本不覆盖旧文件，不静默截断。过期自动删除未处理草稿没有启用。

面板复用 getStateSnapshot；建卡复用 buildCreationSnapshot 和 applyCreationSnapshotToChar。约五百毫秒合并写入、两秒最大等待。正式保存后只清理已确认且匹配的草稿；旧的清理动作不能删除更高序号的新草稿。

恢复进入当前编辑状态，不直接覆盖正式存档。重启进入启动台时会显示未处理草稿，编辑页可恢复、查看已保存状态或放弃。最后一次 ACK 之后的输入仍可能在突然崩溃时丢失。

## 运行时与资源

用户确认只支持 Windows 10/11，已将 Electron 从 22.3.27 升至精确固定的 44.5.1。官方稳定版来源见 [Electron 44.5.1](https://releases.electronjs.org/release/v44.5.1)。保留 contextIsolation 和禁用 nodeIntegration；安装程序增加 Windows 10 最低版本检查，本项目产物为 x64。

提供持久兼容渲染模式，下次启动前调用 disableHardwareAcceleration。GPU 功能与设备信息单独记录，没有凭推测安排自动循环重启。

内存监测为每个进程设置单次 GC、冷却与超时。持续高占用时可以释放闲置五分钟以上的只读预览，编辑页不因此强制重载。

同一操作序列：50 次导航、20 次预览开关，20 个匿名角色，每人 30 个能力，JSON 共 1,489,131 字节。机器为 Windows 10 19045、约 16 GiB 内存，采样时系统可用内存约 2 GiB。

| 运行时与条件 | 第 50 次导航工作集总和 |
| --- | ---: |
| Electron 22.3.27，同一修复代码 | 516 MB |
| Electron 44.5.1，默认条件 | 812 MB |
| Electron 44.5.1，V8 堆限制 256 MiB | 832 MB |

新运行时有明显额外资源成本。工作集求和包含共享页，不能当成独占内存；本轮未检测到持续增长或 OOM。V8 堆限制不等于将整机内存限制为 2 GiB，没有做低内存虚拟机验收。
