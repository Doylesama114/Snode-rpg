# v1.0.8085

发布日期：2026-10-27。

**便携版自更新验证版**——除版本号外与 1.0.8084 相同。

## 用途

应用已按便携方式部署到 `D:\SnodeRPG`（解压 zip，版本 1.0.8084）。本版用于验证 zip 覆盖式自更新：

```
检查 portable.json → 下载 Snode-RPG-1.0.8085-win-x64.zip → sha512 校验
→ 解压 → ping 12s & robocopy /E /IS /IT & start 应用
→ 应用退出 → 覆盖写入 → 启动后版本变 1.0.8085
```

## 验证步骤（在 D:\SnodeRPG 的 1.0.8084 上）

1. 打开 `D:\SnodeRPG\斯诺德跑团.exe`
2. 在启动台点「检查更新」（手动检查会走「下载完立即安装」）
3. 等下载完成（约 190 MB，20–40 秒）
4. 应用会自动退出并在约 12 秒后覆盖安装、重新启动
5. 重开后版本应为 **1.0.8085**

## 成功判据（诊断日志）

