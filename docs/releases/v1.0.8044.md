# v1.0.8044

发布日期：2026-10-06。

修复手机 AI 顾问提示“服务未配置”或长时间停在连接中的问题。

- 使用统一的公开服务配置；APK、GitHub Pages 原始网页、移动资源包和 OSS 网页均包含服务地址，不再依赖读取失效的 OSS 地址文件。API 密钥仍保留在服务端。
- 生产构建校验 HTTPS 地址格式，拒绝无效配置；旧地址不可达时可尝试随包提供的公开服务地址。
- 连接检查覆盖请求及 JSON 响应体的超时，增加顶部“重新连接”按钮，失败后可恢复。
- 修复 SSE 解析器没有调用消息回调的问题，支持 CRLF 与跨分块 UTF-8，回复正常完成后不重复发起生成。
- 兼容网关返回 JSON；中断或超时明确说明并恢复发送状态，不把迟到片段混入新回复。
- 保留会话记录、角色快照与手动顾问入口。自动小贴士开关不受影响。

已安装 v8042/v8043 Android 更新器可在启动台检查资源更新，也可覆盖安装本版 APK。旧更新器需要先覆盖安装一次；无需卸载或清除数据。

线上公开服务健康检查、手机跨域预检及实际问答均已验证；正式安装包与备用移动渠道在发布后独立验收。阿里云存储镜像的账户禁用状态仍由账户所有者恢复，顾问连接不再依赖该镜像。

连接配置在页面初始化前可用，避免在线后仍显示旧的“未配置”引导。修正共享皮肤隐藏顾问标题/状态的问题，让重连与在线状态在手机上可见。
