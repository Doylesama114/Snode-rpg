## 顺带修复：领域注入管线的两处隐患

1. **`apply_cleric_domains.py` 的泄漏清理正则**：原来用非贪婪 `.*?(?=...)` 删除「泄漏到 common 区的隐藏域面板」，标记不成对时会一路吃到下一个 `deity-panel`，把 `<section class="class-features">`（职业专长）和血量计算器整块吞掉。改为**按 `<div>` 深度配对**删除，结构不完整时放弃删除而不是冒险。
2. **`牧师.html` 的 chips 标记错位**：历史注入把 `class-features` 包进了 `<!-- PR-DEITY-CHIPS -->…<!-- /PR-DEITY-CHIPS -->`，导致每次重注入都会连带删掉职业专长/计算器。本次一次性修复该页标记，并在 apply 末尾加自检（`class-features` 与 `pr-hpcalc` 必须各恰好 1 个，否则中止），`verify_cleric_domains.py` 也补了同样两条结构断言。

修复后：`verify_class_hp_calc.mjs` 18P 0F、`verify_class_features.mjs` 4P 0F；渲染快照确认季风之神面板 14 chips / 21 卡片 / 无 JS 错误。
