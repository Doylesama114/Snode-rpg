# v1.0.8083

发布日期：2026-10-27。

**分发方式切换：便携版 zip + 自更新**，彻底不再依赖安装器。

## 为什么换

连续多轮排查的结论：electron-builder 的安装器在更新时会先运行**旧版本的卸载器**，而卸载器只认安装时烘焙的目录；
目录一旦被搬动（D 盘、junction、手工注册表），它要么返回 2 要么空转，静默模式下安装直接中止——这就是反复出现的 `Failed to uninstall old application files: 2`。

而且实验证明：

| 尝试 | 结果 |
|---|---|
| 装到 junction 目录 | 安装器写 0 文件（NSIS CopyFiles 不穿过重解析点） |
| `/S /D=<路径>` | 不生效 |
| 向导里选 D 盘 | 写入 `Uninstall *.exe` 被拒，安装中止 |

所以换成不经过安装器的方案：**下载 zip → 校验 → 解压 → 应用退出后 robocopy 覆盖 → 重启**。

## 本版改动

| # | 改动 |
|---|---|
| 1 | 新增 `electron-app/portable-updater.js`：清单解析、HTTP 下载（带进度/低速熔断）、sha512 校验、tar/PowerShell 解压、解压根定位、替换命令构造 |
| 2 | `main.js` 增加 `PORTABLE_MODE`（Windows 默认启用，`SNODE_UPDATE_MODE=installer` 可临时回退）：检查/下载/安装三个入口全部分流到便携逻辑 |
| 3 | 更新清单改为 `releases/latest/portable.json`（OSS 优先，GitHub Release 资产回退） |
| 4 | `electron-builder.yml` 增加 `zip` 目标，产物 `Snode-RPG-<版本>-win-x64.zip` |
| 5 | CI：构建 `nsis zip` 双目标、生成 `portable.json`（sha512/size/url）、上传 Release、同步 OSS 并发布 `releases/latest/portable.json` |
| 6 | 新增门禁 `verify_portable_updater.mjs`（19 条，含**用真 zip 跑下载→校验→解压→替换**） |

## 更新时序

```
检查 portable.json（OSS → GitHub）→ 下载 zip → sha512 校验 → 解压到临时目录
→ 写待安装版本 → 分离进程：ping 12s & robocopy /E /IS /IT & start 应用
→ 应用 app.exit(0) → 覆盖写入 → 新版本启动 → 校验版本与 pending 一致 → 清理缓存
```

替换用 `robocopy /E /IS /IT`（覆盖+新增），**不用 `/MIR`**：不删除旧文件，避免替换失败时把应用删残。

## 安装说明

便携版不需要安装：解压 zip 到任意目录，直接运行 `斯诺德跑团.exe`。
从本版起，自动更新只走 zip 覆盖，不再调用安装器。
