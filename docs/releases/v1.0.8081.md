# v1.0.8081

发布日期：2026-10-27。

**自动更新真正的最后一道坎**，这次是手工验证过的。

## 证据

把旧卸载器删掉，再手工执行一次更新安装：

```
删除前卸载器: Uninstall 斯诺德跑团.exe
删除后剩余: 0
退出: True code=0        ← 之前一定失败的那一步
文件数: 389               ← 文件完整
新卸载器: 1.0.8080        ← 新版本已写入
```

## 原因

electron-builder 的安装器在 `--updated` 时，会先执行**旧版本目录里的卸载器**：

```nsis
nsExec::Exec '"$INSTDIR\Uninstall 斯诺德跑团.exe" /S _?=$INSTDIR'
${If} $R0 != 0
  MessageBox ... "Failed to uninstall old application files. Please try running the installer again.: $R0"
```

我们的卸载器在这个环境下固定返回 2（目录被搬迁、注册表由外部写入、无卸载记录等多种因素都会导致它空转或失败），而静默安装没有界面可以提示，只能中止 —— 所以你每次都看到同一句报错。

## 修复

拉起安装器之前，先删掉安装目录中的 `Uninstall *.exe`：

```js
function removeOldUninstaller(reason) { ... fs.unlinkSync(...) ... }
// launchInstallerDelayed 内，spawn 之前调用
```

安装器找不到旧卸载器就不会走卸载分支，直接覆盖写入新版本，并生成新的卸载器。卸载功能本身不受影响（新版本会重新生成），「应用和功能」里也照常可卸载。

## 验证

- `verify_update_flow_e2e.mjs` 新增 ⑨ 段：**60P 0F**（含正则命中「Uninstall 斯诺德跑团.exe」而不误伤主程序）
- 手工端到端：删除卸载器后 `--updated /S` 退出码 0
