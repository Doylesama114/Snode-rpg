# v1.0.8075

发布日期：2026-10-27。

**更新链路验证版**——除版本号与说明外无功能变更。

## 为什么要发这一版

v1.0.8074 把安装器改成了「应用退出后延迟 12 秒再拉起」，但**这个修复只有在出现更新版本时才会被触发**。为了让 8074 的修复能当场验证，这里做一个只改版本号的小版本。

## 预期表现（在 1.0.8074 上）

1. 启动约 90 秒后自动检查更新
2. 从阿里云 OSS 下载 150 MB（约 20–35 秒）
3. 启动台提示「更新已就绪」
4. 关闭应用 → **应用彻底退出后约 12 秒**，安装器在后台启动并静默安装
5. 重新打开 → 版本变成 1.0.8075

安装完成后 `%LOCALAPPDATA%\snowd-skill-tree-updater` 应只剩 `current.blockmap`（约 0.2 MB），下载的 150 MB 安装包会被自动清理。

## 验证要点（日志）

| 事件 | 含义 |
|---|---|
| `updater-install-launched` | 延迟拉起生效，含 12000 ms 延迟与安装包路径 |
| `updater-install-applied` | 重启后版本与待装版本一致，安装真的落地 |
| `updater-cache-purged` | 装完自动清理生效 |
| `temp-env-normalized` | TEMP 硬化生效（若系统 TEMP 与 `%LOCALAPPDATA%\Temp` 不一致时才会出现） |

如果失败，会看到 `updater-install-not-applied` 或 `updater-error`，里面带具体原因。
