# v1.0.8042

发布日期：2026-10-05。

修复 Android 资源更新停在旧版、更新中断后资源不完整和缓存混用导致白屏的问题。

- APK 内置完整核心与卡牌资源，首次启动和断网时也能进入应用。
- 更新清单支持阿里云、GitHub Pages 和 GitHub Release；资源下载按清单校验长度及 SHA-256，主地址失效时尝试备用地址。
- 下载与解压在独立目录完成，完整验证后再切换版本；失败保留可用资源，损坏缓存可修复，旧清单不能降级。
- 保留已加载页面使用的资源目录。后台更新就绪后提示先保存角色再重新加载，不直接关闭玩家正在编辑的页面。
- 本地资源不进入 WebView HTTP 缓存，更新切换清理磁盘缓存，保留相同网页存储来源及角色存档、提示偏好。
- Android 检查更新调用原生资源更新，下载按钮选择 APK；旧更新器给出覆盖安装新版的说明。
- 发布流程独立上传 APK、核心包、卡牌包和移动清单，不再因 OSS 镜像异常阻断主要移动发布。

升级方式：旧 Android 更新器只有阿里云渠道，需要先下载本版 APK 覆盖安装一次。无需卸载；使用同一签名和包名保留应用数据。之后可通过备用渠道更新资源。

当前阿里云 OSS 返回 HTTP 403 / UserDisable，账号禁用仍需要账号所有者检查账户状态（可能与欠费有关）并恢复。该状态不由客户端代码修复；GitHub 的独立发布与 APK 内置资源提供可用路径。阿里云恢复后可重跑镜像任务。

Windows 10/11 64 位版本同步发布，Electron 44.5.1 不变。
