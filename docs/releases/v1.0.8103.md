# v1.0.8103

发布日期：2026-11-06。

修复帮助页规则章节的排版错位。

## 一、问题

`斯诺德跑团/help.html` 的「基本规则」段（`#s0`）**缺少自己的 `</div>` 闭合标签**，于是后面的 10 个规则段整段被解析成它的子节点：

| 检查 | 修复前 |
|---|---|
| `<div>` / `</div>` | 1094 / **1093** |
| `main.help-content` 直接子元素 | **1**（应为 12） |
| 12 个 section 中被嵌套的 | **11** |
| 几何 | `s0` left=382 width=920；`s1`–`s10` left=**411** width=**862** |

表现就是：规则段整体右移 29px、变窄 58px、出现双重边框，标题和表格与卡片边缘对不齐，看起来像「内容跑到了 section 外面」。

此外还发现 3 组内容**确实落在所有 section 之外**（各自 section 的 `</div>` 提前闭合）：

- 「子职业 / 附赠职业」两段（应在**升级规则**）；
- 「补充规则（10.25 更新）」标题 + 列表（应在**幕间规则**）；
- 3 段「个性与背景 → 色彩标识」说明（应在**技能点和色彩标识规则**）。

## 二、修复

1. 在 `#s1` 之前补上 `#s0` 的 `</div>`；
2. 把上述 3 组的 section 闭合标签**下移**到内容之后（等价于把内容收进正确章节）；
3. 不改任何文字内容、不改样式、不改顺序。

## 四、防回归

新增 `scripts/verify_help_structure.py`，已并入 `verify_all.mjs`：

1. `help.html` 的 `<div>` 开闭必须相等；
2. 两个面板里的每个 `div.section` 必须是 `main.help-content` 的**直接子元素**；
3. 任何 `.section` 内部不得再嵌套 `.section`；
4. `p/h2/h3/ul/ol/table/blockquote` 必须落在某个 section 内。

已用「去掉一个 `</div>` 的副本」做过反向验证：该脚本会明确报错，不会静默通过。
