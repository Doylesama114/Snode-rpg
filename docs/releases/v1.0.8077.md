# v1.0.8077

发布日期：2026-10-27。

**更新链路验证版**——除版本号外与 1.0.8076 完全一致。

## 用途

1.0.8076 修好了三个真实缺陷（`chr(34)` 崩溃、`spawn` 缺 `windowsVerbatimArguments`、`getPath('localAppData')` 非法），并用「真实执行命令」的校验证明命令能跑。但**真实的 NSIS 安装动作**只有在出现更新版本时才会发生，所以发这个小版本做闭环验证。

## 验证步骤（在 1.0.8076 上）

1. 打开应用，等 2–3 分钟（90 秒检查 + 150 MB 下载约 20–35 秒）
2. 启动台显示「更新已就绪」
3. 关闭应用 → **等 15–20 秒**（12 秒延迟 + 安装器执行）
4. 重新打开 → 版本应为 1.0.8077

## 成功后应看到

```
updater-install-launched   → 延迟拉起（ms=12000 + 安装包路径）
updater-install-applied    → 重启后版本匹配，安装真的落地
updater-cache-purged       → 150 MB 安装包被自动清理
```

`%LOCALAPPDATA%\snowd-skill-tree-updater` 应只剩 `current.blockmap`（约 0.2 MB）。
