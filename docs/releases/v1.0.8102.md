# v1.0.8102

发布日期：2026-11-05。

修复 1.0.8101 的 Mac 发布缺口：**1.0.8101 只发布了 DMG，没有 zip**，而应用内更新需要 zip，因此 Mac 用户点更新会下载到 DMG 后失败。

## 一、问题

`scripts/build-mac.mjs` 里写死了 `--mac dmg`，即使 `electron-builder.mac.yml` 的 target 里加了 `zip`，实际构建也不会产出 zip。

结果：

- 1.0.8101 的 Release 里只有 `-mac-arm64.dmg` / `-mac-x64.dmg`，没有 zip；
- 客户端 `pickAsset()` 会优先 zip、没有 zip 时退回 dmg；
- 而安装脚本用 `ditto -x -k` 解压 zip → 拿到 dmg 必然失败。

## 二、修复

| 改动 | 说明 |
|---|---|
| `scripts/build-mac.mjs` | 构建目标改为 `--mac dmg zip`，两种产物都生成 |
| `.github/workflows/build-mac.yml` | 发布步骤用 `nullglob` 取现存的 dmg/zip；一个都没有时明确报错，不再把字面量 glob 当文件名上传 |
| `electron-app/main.js` | 若某版本只有 DMG，直接提示「请手动下载安装」，不再让用户下载完才发现装不上 |

## 三、验证（真实 macOS）

在 `codex/mac-installer-8102` 分支上跑完整构建：

```
build-mac (arm64, macos-15)        = success
build-mac (x64, macos-15-intel)    = success
mac-manifest                       = success   ← dmg + zip 都拿到，mac.json 生成成功
```

`mac-update-e2e`（macos-14 / macos-15）依旧全绿；`verify_update_flow_e2e.mjs` 122P 0F。

## 四、Mac 用户怎么升级

- 从 1.0.8102 起：应用内点更新 → 自动下载 zip → 退出后自动覆盖并重启；
- 仍在 1.0.8100/8101 的用户：需要手动下载一次 1.0.8102 的 DMG（拖入「应用程序」，首次右键打开），之后就能走应用内更新；
- 若提示「已损坏」：右键 → 打开，或执行 `xattr -dr com.apple.quarantine /Applications/斯诺德跑团.app`。
