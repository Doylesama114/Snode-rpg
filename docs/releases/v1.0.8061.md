# v1.0.8061

发布日期：2026-10-15。

技能正文显示修复 + 术士抉择标题归位。

## 一、技能正文缺失修复（6 个技能）
- 根因：解析器的换行判定 text.endswith("天赋树") 本意识别「四阶天赋树」这类章节标题，却误伤了任何以「…一阶天赋树」结尾的正文，导致正文被静默丢弃；同时 5 个技能存的 source.para_start 指到了列表里的同名条目。
- 修复：把该判定收紧为「短标题才算」；并对受影响技能重新定位与刷新。
- 涉及：法师「趁势一击」（正文整段缺失）、守望者「痛楚忍耐」、谋士「锦囊妙计」「惑人低语」「扰咒术」「弑主」。
- 页面经规范生成器重建（法师/守望者/谋士/术士四页），血量疲劳计算器完好。

## 二、术士抉择标题（D1/D2/D3/D4）归位
- 此前 D1/D2/D3 被当作普通描述文字平铺在父技能卡片里，看着不知所谓。
- 现已明确：D 标题属于它所统领的那个技能，因此渲染在【该技能自己的卡片】顶部，并标注所属父技能。
- 映射：魔力萦绕 → D1 虚弱诅咒 / D2 扰咒术 / D3 魅惑人形；魔力恩赐 → D1 灼热射线 / D2 次级召唤术 / D3 鉴定术 / D4 雷鸣斩；魔力焕发 → D1 旋刃魂曲 / D2 魔力泉涌 / D3 守护演奏 / D4 魔法闪耀。
- 父技能（魔力萦绕/魔力恩赐/魔力焕发）卡片内不再出现裸 D 标记。
