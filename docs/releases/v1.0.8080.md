# v1.0.8080

发布日期：2026-10-27。

**更新链路验证版**——除版本号外与 1.0.8079 相同。

## 背景：安装器终于对了

| 版本 | 形态 | 结果 |
|---|---|---|
| ≤1.0.8077 | assisted（`oneClick: false`） | 更新时静默卸载总返回 2，永远装不上 |
| 1.0.8078 | oneClick + preInit 写 HKLM | 安装器退出码 2（无管理员权限） |
| **1.0.8079** | **oneClick + preInit 只写 HKCU** | **安装成功**，已装在 `D:\SnodeRPG` |

## 这版要验证什么

oneClick 是覆盖式更新：不卸载旧版本，直接把新文件写进同一目录。之前失败的「Failed to uninstall old application files: 2」在 oneClick 下根本不会出现。

## 验证步骤（在 1.0.8079 上）

1. 打开 `D:\SnodeRPG\斯诺德跑团.exe`
2. 等 2–3 分钟（90 秒检查 + 150 MB 下载约 20–35 秒）
3. 启动台提示「更新已就绪」
4. 关闭应用 → 等 15–20 秒（延迟拉起 + 覆盖安装）
5. 重新打开 → 版本应为 **1.0.8080**

## 成功判据

```
updater-install-launched  → 延迟拉起（ms=12000）
updater-install-applied   → 重启后版本匹配
updater-cache-purged      → 150 MB 安装包被清理
```

更新缓存 `%LOCALAPPDATA%\snowd-skill-tree-updater` 应只剩 `current.blockmap`（约 0.2 MB）。
