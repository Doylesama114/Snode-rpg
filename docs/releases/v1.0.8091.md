# v1.0.8091

发布日期：2026-10-29。

新增**安装器诊断日志**，用户可以把日志一键导出发给开发者，用来定位「更新装不上」类问题。

## 一、安装器日志（新增）

每次运行 Setup，都会向下面这个文件**追加**一段记录（不覆盖历史）：

```
%APPDATA%\snowd-skill-tree\installer-logs\setup-<版本>.log
```

记录内容：

| 项 | 用途 |
|---|---|
| `time` / `version` | 定位是哪次、哪版安装 |
| `installdir` / `exedir` / `cmdline` | 安装器把目录认成了什么、是谁用什么参数拉起的 |
| `appdata` / `temp` | 环境差异排查 |
| `whoami /groups` 输出 | **判断是否提权**（Medium/High/Low Integrity，能否杀进程的关键） |
| `tasklist` / `find` 输出与退出码 | 安装器当时能不能看见目标进程 |
| `kill-attempt-N exit=…` | 每次 taskkill 的返回码（0 杀掉 / 128 不存在 / 5 权限不足） |
| `check-app: …` | 最终结论 |
| `uninstall-old: …` | 旧卸载器结果（迁移桥是否触发） |

安装失败弹窗里会直接显示该日志的**完整路径**，用户复制发过来即可。

## 二、应用侧：一键导出打包

启动台「桌面诊断」区域的按钮改为**导出诊断日志**，导出一个 `.txt`，内容包括：

- 版本 / 系统 / exe 路径 / userData / 日志目录；
- 应用日志（`desktop.jsonl` 全文）；
- **所有安装器日志**（`installer-logs/*.log`）。

导出后状态栏会显示「含安装器日志 N 份」，用户只需把这一个文件发过来。
