# v1.0.8082

发布日期：2026-10-27。

**更新链路验证版**——除版本号外与 1.0.8081 相同。

## 这版验证什么

1.0.8081 修掉了自动更新最后一道坎：安装器 `--updated` 会先运行旧卸载器，而它固定返回 2。现在拉起安装器前会先删除 `Uninstall *.exe`，安装器直接覆盖写入。

手工验证过的证据：

```
删除前卸载器: Uninstall 斯诺德跑团.exe
删除后剩余: 0
退出: True code=0        ← 之前必然失败的那一步
文件数: 389               ← 文件完整
新卸载器: 1.0.8080        ← 新版本写入成功
```

## 验证步骤（在 1.0.8081 上）

1. 打开 `D:\SnodeRPG\斯诺德跑团.exe`
2. 等 2–3 分钟（90 秒检查 + 150 MB 下载约 20–35 秒）
3. 看到「更新已就绪」后正常关窗
4. 等 15–20 秒
5. 重新打开 → 版本应为 **1.0.8082**

## 成功判据（日志）

```
uninstaller-stripped       → 旧卸载器已删除（count=1）
updater-install-launched   → 延迟拉起（ms=12000）
updater-install-applied    → 重启后版本匹配
updater-cache-purged       → 150 MB 安装包被清理
```
