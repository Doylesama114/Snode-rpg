# v1.0.8079

发布日期：2026-10-27。

修 1.0.8078 装不上的问题。

## 现象

1.0.8078 的安装器退出码 **2**，什么都没装（`D:\SnodeRPG` 与默认目录都不存在）。

## 原因

`preInit` 里同时写了 HKLM 和 HKCU：

```nsis
WriteRegExpandStr HKLM "${INSTALL_REGISTRY_KEY}" InstallLocation "D:\SnodeRPG"   ; 需要管理员
WriteRegExpandStr HKCU "${INSTALL_REGISTRY_KEY}" InstallLocation "D:\SnodeRPG"
```

但配置是 `perMachine: false`（按用户安装，不弹 UAC），没有管理员权限 → 写 HKLM 失败 → 安装器直接中止。

## 修复

只写 HKCU：

```nsis
!macro preInit
  SetRegView 64
  WriteRegExpandStr HKCU "${INSTALL_REGISTRY_KEY}" InstallLocation "D:\SnodeRPG"
!macroend
```

per-user 安装的安装位置本来就记录在 HKCU，安装器与更新器读同一个键，因此安装和后续自动更新都会落在 `D:\SnodeRPG`。

## 说明

从 assisted 版（≤1.0.8077）仍需要手动安装一次；装好 oneClick 版之后，后续更新才会走覆盖式更新。
