# v1.0.8041

发布日期：2026-10-03。

启动台新增“提示设置”，可以长期关闭自动新手引导和顾问主动提示，同时保留手动顾问功能。

- “自动新手引导”关闭后，启动台、角色创建页与角色选择页都不再自动出现引导；首次展示会被记录，未完成也不会每次启动重来。手动重看不会重新打开自动模式。
- “顾问自动提示”默认关闭，控制随机小贴士和建卡主动气泡；顾问入口、手动问答和主动查看建卡建议仍然可用。
- 设置保存到本机，跨窗口实时同步，正常重启与升级保留。保存失败会明确说明，不把临时关闭当作已永久保存。
- 关闭自动提示时清理相关计时器，并屏蔽在途自动请求的迟到气泡。自动建议与手动问答的流式回复分别关联，避免内容混入。
- 同步 Android 资源包与网页提示入口，并修正建卡快照的职业变量引用。
- 整合角色表结构、主体与字段候选识别的完善，修正空白模板优先于已填写角色表的问题；保留原始内容、待确认项目和其他参考表。

Windows 桌面版支持 Windows 10/11 64 位。当前版本沿用 Electron 44.5.1。

发布前运行提示偏好、完整角色导入、全量业务与真实桌面门禁，正式安装产物还会经过启动和故障恢复检查。
