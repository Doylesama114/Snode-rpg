# v1.0.8047

发布日期：2026-10-08。

修复旧版 Mac 安装包中，顾问读取角色创建页资料时出现 `char is not defined` 的问题，并正式提供两种 Mac 架构的 DMG 安装程序。

- 角色快照正确读取 `CHAR.className`。顾问可以取得所选职业和创建资料，不再因变量名大小写错误而在发送请求前中断。
- 新增网页及 Electron 副本的角色快照回归，覆盖空表单、已选职业和八个创建步骤，接入 Windows 与 Mac 发布流程。
- Mac 安装包使用线上最新桌面壳及 Electron 44.5.1，包含桌面诊断、窗口生命周期和恢复模块，保留已有角色存档。
- Mac 保留编辑快捷键，关闭窗口后可从 Dock 重开；更新下载匹配 Apple 芯片或 Intel 的安装程序。
- 延续 v8046 的手机帮助页搜索与定位、顾问连接修复和角色资料保护。

## 安装与更新

- Windows：下载 `Snode-RPG-Setup-1.0.8047.exe` 覆盖安装，或在应用内检查更新。
- Apple 芯片 Mac：下载 `Snode-RPG-1.0.8047-mac-arm64.dmg`。
- Intel Mac：下载 `Snode-RPG-1.0.8047-mac-x64.dmg`。
- Mac 双击 DMG 后将应用拖入“应用程序”；更新前退出旧应用再替换。
- Android：下载 `Snode-RPG-1.0.8047.apk` 覆盖安装；v8042 及以上也可检查资源更新。

Mac 包使用本地 ad-hoc 签名，尚未配置 Apple Developer ID 公证。首次打开若被系统拦截，请在“隐私与安全性”中允许打开。Mac 包提供公开配置模板，AI 顾问密钥沿用个人配置，详见 [Mac 配置说明](../macos-packaging.md)。

阿里云 OSS 账户既有的 UserDisable 问题可能影响镜像渠道。GitHub Release 和现有 GitHub Pages 备用资源渠道仍用于发行与更新；镜像状态以本版流水线及上线检查结果为准。
