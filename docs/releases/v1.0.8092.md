# v1.0.8092

发布日期：2026-10-31。

按需求取消角色面板的两处限制：**学习技能的阶位锁** 与 **抉择的选择锁**。

## 一、改动

| 锁 | 原行为 | 现在 |
|---|---|---|
| 阶位锁 | 一阶/二阶默认开放；三阶及以上需花经验值解锁（并有主职业等级门槛），未解锁时整阶技能不展示，只显示「解锁 X 阶」按钮 | `isTierUnlocked()` 恒为真，**所有阶位直接可学**，解锁按钮自然消失 |
| 抉择锁 | 抉择 A 最多 1 项、抉择 B 最多 2 项……选满后其余选项变灰、不能学习 | `getChoiceGroupStatus().full` 恒为 `false`，**选满后仍可继续学习**；`(已选 X/Y)` 仍显示，仅作提示 |

两处都是单点开关，代码里带 `v1.0.8092` 注释，日后要恢复只需还原这两行。

## 二、没有改动的部分

- `isRuleLockedAbility()`：规则明文「无法通过任何方式修改的能力」，与本次无关；
- 技能槽位上限、前置/额外条件提示：属构建规则提示，保留；
- 存档字段 `unlocked_tiers` 继续读写，旧档照常加载（只是不再影响展示）；
- 「重置所有非锁定技能」行为不变（它依据技能条目自带的 `locked` 标记，不是阶位锁）。

  - 一~七阶 + 通用全部 `isTierUnlocked === true`；清空 `unlocked_tiers` 后三阶仍可学；

## 四、副作用说明

1. 阶位不再消耗经验值：`unlockTier()` 不再被触发，`state.xp` 不会因此减少；过去已花掉的 XP **不自动退回**。
2. 抉择组允许超选：会显示 `(已选 3/1)` 这类计数，属取消限制后的预期表现。
