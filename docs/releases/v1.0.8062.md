# v1.0.8062

发布日期：2026-10-15。

资料库新增「稀有装备」入口标签页。

## 一、资料库 · 稀有装备入口（修复"找不到入口"）
- 现象：资料库页里看不到稀有装备的入口。
- 根因：入口原先由一段运行时脚本插入到 main 容器，而资料库页的 main 是隐藏容器，导致入口虽存在于 DOM 却尺寸为 0×0、不可见。
- 修复：改为与「物资大全」「基础规则」一致的静态结构 —— 独立的标签页（data-tab="rare"）+ 对应的 panel（panel-rare）内容卡片。
- 结果：资料库现有 5 个标签（创建流程 / 个性与背景创建规则 / 物资大全 / 稀有装备 / 基础规则），入口卡片实测可见（高 85px、宽 910px）。

## 二、仓库清理
- 移除此前误提交的临时物与系统缓存（%SystemDrive% 与 Microsoft 缓存 db、探测目录 _scratch、已完成的一次性计划与审查文档），相关文件移入 备份区/2026-10/根目录清理/。
