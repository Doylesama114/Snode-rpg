# v1.0.8074

发布日期：2026-10-27。

修复自动更新最后一环：**安装器在应用还没退干净时被拉起**，静默模式下 NSIS 无法弹「关闭应用」对话框，直接返回 2 —— 也就是你看到的 `Failed to uninstall old application files. Please try running the installer again.: 2`。

## 一、证据链

你机器 2026-10-27 03:08（UTC）的日志：

```
03:08:30  New version 1.0.8073 has been downloaded …
03:08:33  Install on explicit quitAndInstall
03:08:33  Install: isSilent: true, isForceRunAfter: true
03:08:33  Executing: …\Snode-RPG-Setup-1.0.8073.exe with args: --updated,/S,--force-run
03:08:36  Update installer has already been triggered. Quitting application.   ← 应用还在退出，安装器已经开跑
```

安装器立刻去卸载旧文件，但应用进程/子进程还占着文件 → 卸载器返回 2 → 安装中止。

## 二、改动

| # | 改动 | 说明 |
|---|---|---|
| 1 | `autoInstallOnAppQuit = false` | 不再让 electron-updater 在退出瞬间拉起安装器 |
| 2 | 新增 `launchInstallerDelayed()` | 用分离进程 `cmd /c ping 127.0.0.1 -n 12 >nul & "<安装包>" --updated /S --force-run`，**先让应用彻底退出，12 秒后再安装** |
| 3 | `child.unref()` | 应用退出后安装器仍能独立跑完 |
| 4 | 记录 `info.downloadedFile` | 安装包路径来自 electron-updater 实际下载结果，不猜缓存目录 |
| 5 | 只拉起一次 | `installerLaunched` 守卫，避免重复安装 |
| 6 | 退出兜底 | `will-quit` 时若已下载但未拉起，仍走延迟安装 |

## 三、验证

- `verify_update_flow_e2e.mjs`：新增 **11 条**断言（延迟拉起、分离进程、只拉一次、不再调用 quitAndInstall 等），并把 3 条旧断言同步到新设计，**58P 0F**
- 全量门禁：Clean 57/57 · Tests 913P 0F（4 项为环境缺 Electron 模块）

## 四、说明

这一版必须**手动安装一次**：你当前跑的是 1.0.8072，它里面的安装逻辑还是旧的（下载完立刻拉起安装器）。从 1.0.8074 起，下一次自动更新才会走「延迟 12 秒」的新路径。
