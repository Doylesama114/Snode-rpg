# v1.0.8073

发布日期：2026-10-27。

桌面端更新链路两项维护：**安装包自动清理**（回收 C 盘空间）与 **TEMP 环境加固**（避免安装器在异常 TEMP 下直接失败）。

## 一、问题：更新装不上，且安装包越堆越多

实测（本机）：

| 现象 | 证据 |
|---|---|
| 更新能下载、装不上 | 日志：`New version 1.0.8072 has been downloaded`（153 MB / 17 秒）→ `Executing ... --updated,/S,--force-run` → 之后再无安装记录，安装目录从未出现 |
| 安装器报错 | `Error writing temporary file. Make sure your temp folder is valid.` / `Failed to uninstall old application files ... : 2` |
| 安装包堆积 | `%LOCALAPPDATA%\snowd-skill-tree-updater` = **300.4 MB**（`pending\Snode-RPG-Setup-1.0.8072.exe` 150 MB + `installer.exe` 150 MB 同一份存了两遍） |

根因：用户级环境变量 `TEMP`/`TMP` 被改成了 `D:\dsh-temp`（此前做「不写 C 盘」治理时的副作用），NSIS 安装器在该目录下**无法解压自身**，一启动就失败。用同一个安装包、同一台机器，只把 TEMP 指向 `%LOCALAPPDATA%\Temp`，安装立刻成功（exit 0）。

## 二、本版改动

| # | 改动 | 说明 |
|---|---|---|
| 1 | **TEMP 加固** | 启动时把 `process.env.TEMP/TMP` 归一化到 `%LOCALAPPDATA%\Temp`（不依赖 TEMP 本身推导），子进程（含安装器）不再继承坏值 |
| 2 | **装完即清** | 更新装完后的首次启动（版本与 `pendingVersion` 匹配）删除 `pending\` 与 `installer.exe` |
| 3 | **7 天兜底清理** | 每次启动清理缓存目录中 7 天前的文件（下载了没装、反复失败的情况）；保留 `update-info.json` |
| 4 | **不误删** | 清理前检查是否有正在下载/待安装的更新（`updaterBusy()`），有则跳过 |
| 5 | 关闭差分下载 | OSS 不支持 `multipart/byteranges`，此前每次日志都报 `Cannot download differentially` 再回退全量；关掉省一次无用请求 |
| 6 | 关闭 web 安装器告警 | `disableWebInstaller = true` |

## 三、效果

- 本机缓存：**300.4 MB → 0.2 MB**（已手动按同一规则清理）
- 新版本起，每次更新结束后自动回收，不再累积；长期未安装的包 7 天后也会被清掉

## 四、验证

- `verify_update_flow_e2e.mjs`：新增 **11 条**断言（加固函数、清理时机、保留名单、busy 保护、差分/web 开关），**47P 0F**
- 全量门禁：Clean 57/57 · Tests 913P 0F（4 项为环境缺 Electron 模块）

## 五、给用户的话

如果仍装不上，请检查自己的 `TEMP`：

```powershell
[Environment]::GetEnvironmentVariable('TEMP','User')
[Environment]::GetEnvironmentVariable('TMP','User')
```

正常应为 `C:\Users\<你>\AppData\Local\Temp`。指向其他位置（尤其是不存在或不可写的目录）会让**所有** NSIS 安装包失败，不只是本应用。
