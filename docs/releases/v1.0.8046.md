# v1.0.8046

发布日期：2026-10-07。

修复手机帮助页检索后无法看到正文的问题。

- 补齐规则／世界观切页接口，跨页搜索会显示对应正文并更新章节链接。
- 每次检索以当前渲染内容建立索引；手机表格转换后的卡片可以搜索，隐藏的旧表格不再产生结果。
- 搜索直接定位并避开悬浮目录，避免跨越长篇正文的滚动动画与插图懒加载同时发生，使结果被推离屏幕。延迟图片加载后自动校正，玩家操作后停止跟随。
- 保留行内格式并完整高亮跨标签的关键词；排除朗读按钮、提示和隐藏内容，避免重复计数。
- 支持检索按钮、手机键盘搜索和回车；中文输入法确认不触发检索。修改或清空关键词会取消旧结果和待执行的定位。
- 输入框适配16px字体和明暗主题，保持文字可读。

回归覆盖360／390／1440视口的规则与世界观双向跳转、手机卡片、下一条／上一条、动态内容、清空与输入法、明暗主题；同时检查实际Electron帮助页。发布后验证APK签名、内置资源与可更新资源包，并以实际流水线和下载结果为准。没有连接实体安卓手机，不将浏览器模拟视口称为手机真机测试。

Android v8042及以上可在启动台检查资源更新，也可覆盖安装本版APK。旧更新器建议覆盖安装APK。Windows与网页同步发布；阿里云OSS账户仍处于UserDisable状态，可能使旧渠道更新失败，GitHub Release与独立GitHub Pages资源渠道继续提供更新。

帮助页原生焦点滚动采用即时方式，避免输入框尚在平滑滚动时切换页签，覆盖搜索的正文定位。目录按钮继续使用明确的章节跳转处理。
