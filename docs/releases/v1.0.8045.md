# v1.0.8045

发布日期：2026-10-06。

修复角色学习面板的抉择名额误锁及技能栏占用边界。

- “已达上限锁定”来自抉择组选项名额，和职业技能栏总容量分开计算。按同一职业来源的不同已选项计数，不再让重复记录、其他来源同名能力、自定义或待确认条目误锁剩余选项。
- 不删除或合并玩家记录，已有 UID、原始文本与来源保留；真正达到抉择上限时仍限制学习，并显示“本抉择组选项已满”。
- 空白技能占位记录不计入技能栏；免费不占栏能力及附赠职业能力继续独立处理。
- 面板显示实际占栏/规则上限。六级法师标准容量仍为20栏；真实满栏继续提供替换选择，不扩大规则上限。
- 不再用描述中互不相关的“无法”和“覆盖”推断新学技能永久锁定；明确不可修改/覆盖/替换的规则继续生效。已有玩家保存的锁定标记保留。
- 职业等级未确认或容量为零时明确提示检查职业信息；不再将空列表误报为“所有技能已锁定”。
- 修复“展开全部”按钮重新收起分组的问题。

已在浏览器与真实 Electron 中验证法师六级、重复记录的实际学习按钮、满组限制、满栏替换、来源区分和 UID 保留。没有取得玩家原始存档，不能声称复现了该玩家档案；如仍出现锁定，需按界面指示核对具体抉择组已选项及保存记录。

Android v8042及以上可在启动台检查资源更新，也可覆盖安装本版 APK；Windows与网页同步发布。阿里云镜像的账户状态仍以实际下载检查为准，GitHub与备用资源渠道继续提供更新。
