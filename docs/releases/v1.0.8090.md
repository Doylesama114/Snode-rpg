## 为什么发这个版本

1.0.8089 发布时，阿里云 OSS 返回 403（账号侧问题），`mirror-oss` 任务失败，OSS 上的 `portable.json` / `latest.yml` 停在 1.0.8087。
OSS 恢复后，为了让镜像重新同步，我删除了远端 tag 并重新推送以触发流水线；结果是：

- OSS 侧补齐成功（`portable.json` = 1.0.8089、`Snode-RPG-1.0.8089-win-x64.zip` 190.5 MB、`Setup.exe` 均 200）；
- **GitHub Release 侧的 v1.0.8089 变成一个没有可见资产的空发布**（`expanded_assets` 仅 4.5 KB，API `/releases/tags/v1.0.8089` 对匿名返回 404），`releases/latest` 仍指向 1.0.8088。

由于本地 `gh` 未登录、无法直接补传或发布草稿，改用正常发版路径重建：**1.0.8090 = 1.0.8089 的内容 + 完整发布产物**。
