# v1.0.8056

发布日期：2026-10-11。

职业页新增「血量 / 疲劳计算器」，并让「健壮」专长按选择等级分级生效。

## 血量 / 疲劳计算器（18 个基础职业页）
- 每个职业页在「职业专长」之后新增计算器：初始生命/疲劳、每级成长公式、1–20 级速查表。
- 数值直接复用与角色面板相同的计算实现（SNOWD_CHARACTER_STATS.totalHP / totalFP），逐职业比对与面板完全一致。
- 输入：等级、体质、关键属性（战舞者等「A 或 B」型可二选一）、种族、体型、个性背景（全部 42 个）、健壮专长。
- 速查表按宽度自适应多排（桌面 4 组），等级列四组配色、当前等级高亮。
- 左侧导航新增「血量/疲劳计算器」锚点。
- 数据由 scripts/gen_hp_calc_data.mjs 从 panel_data.js 抽取生成 5 KB 的 hp_calc_data.js，不引入 4.6 MB 的完整数据文件。

## 健壮专长分级生效
- 特殊专长只能在 4 / 8 / 13 级获得（来源：冒险者基础规则「升级规则」表）。
- 健壮加成 = 2 × max(0, 当前等级 − 选择等级 + 1)，早于选择等级时为 0。
- 例：4 级选择健壮时，20 级加成为 +34（此前的算法按总等级全额计入，会得到 +40）。
- 勾选健壮后才会出现「选择等级」下拉。

## 已知偏差（有意保留）
- 角色面板与导入仍按总等级全额计算健壮，与规则不符；因无玩家反馈健壮算错，本次未改动存档与面板，仅计算器采用正确规则。
- 因此勾选健壮时，计算器与面板的数值会不同；门禁对此刻意不做「与面板一致」断言，改为按规则手算校验。
