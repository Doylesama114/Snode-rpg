# v1.0.8057

发布日期：2026-10-11。

建卡语言选择器：暂时关闭「兽语」与「元素语」的选择。

- 这两门语言在选择器中保留按钮，但置为不可点击（灰化 + 虚框 + 标注「（暂未开放）」+ 悬浮说明），后续版本可视情况开放。
- 规则集中在角色创建页的一个常量 DISABLED_LANGUAGES 中，后续调整只需改这一处。
- 特别区分：名字相近的「兽人语」不受影响，仍可正常选择。
- 若草稿或角色数据中已选中这两门语言，仍可点击取消，避免因计数校验而卡住保存。
- 背景的语言数量要求（任选一门 / 任选两门）与保存前校验逻辑均未改动；禁用后仍可选语言 16 门，任何背景的需求（最多 2 门）都能满足。

验证：内联脚本语法检查 0 错误；真实背景「侍僧」（需 2 门）实测——兽语/元素语不可点击且点击无效、兽人语可选、确认回调正确返回 2 门语言；360/390/1440 无横向溢出、0 JS 错误。
