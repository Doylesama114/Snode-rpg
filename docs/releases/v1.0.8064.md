## 一、个性背景色彩标识（新数据）

- 数据源更新为 `10.22内容更新/个性与背景创建规则.xlsx`（160,981 B，43 张表），已替换仓库根同名文件，旧版备份于 `_scratch/_backup_bg_xlsx/`。
- 新增 `scripts/build_bg_colors.py`：读取个性四类（特点 / 理念 / 羁绊 / 缺陷）每个选项在序列号列上的实心底纹，写入 `职业页/数据/bg_personality.json` 的 `colors` 并列字段（与文本数组下标对齐），并同步 `bg_personality_data.js`。
- 覆盖 42 个背景 × 26 项 = **1092 项**；色值分布：白 138 / 黑 136 / 黄 132 / 粉 129 / 红 115 / 青 84 / 棕 78 / 紫 78 / 橙 65 / 蓝 58 / 绿 45 / 浅 34（含 2 个无填充按白色、1 个 `#FFC000` 归黄）。
- 背景的**特殊选择**（神祇 / 罪名 / 专职 / 学术领域等，共 64 项）经 fillId 级核验为表格基线底色，**不给予色彩标识**。
- 文本同步修正：乐师 · 缺陷第 3 项标点；雇佣兵 · 特点 **7 → 8 项**（新增首项，原 1–7 顺移）。
- 顺带修复既有数据错误：平民英雄的「命定事件」10 项历史上被并入 `traits`（导致特点显示 18 项），现 `traits` 恢复 8 项，命定事件独立为 `fate_events`。

## 二、界面显示

- 新增 `斯诺德跑团/bg_mark.js`：色名映射（工作簿色值 → 项目 14 色词表）、12×12 色块（浅色自动深描边）、按文本回查颜色、只读派生角色色彩标识、导入侧剥离色名后缀。
- **角色创建页**：个性弹层每个选项前置色名（`【黄】…`），选中后在下方显示真实色块与色名；自定义项提示改为「请与 DM 商议后再确定此自定义内容的色彩标识」，并在弹层顶部常驻「请在自定义前与 DM 进行商议，自定义个性背景将根据实际情况斟酌提供色彩标识」。
- **角色面板页**：个性背景卡新增只读「色彩标识」汇总行（如 黄色 / 白色 / 紫色 / 黑色），四个字段各自前置色块；`renderStory` 同步（该容器为隐藏的 legacy 块）。
- **资料库**：特点 / 理念 / 羁绊 / 缺陷选项前插色块；检索支持按色名筛选（搜「黄色」可筛出含该标识的选项）；顺手修复 `.bgOptionGrid` 在 360px 下的横向溢出。
- **导出文档**：个性四类文本后追加色名，如 `我崇拜某个英雄…（黄）`；`上传角色.html` 导入侧新增剥离规则（仅剥离末尾色名括号，不改写其它括号内容）。
