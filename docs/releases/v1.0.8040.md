# v1.0.8040

发布日期：2026-10-03。

本版本包含角色导入与技能详情修复，以及 Windows 桌面启动、白屏和崩溃恢复改进。

## 角色和技能

- 更新全职业技能索引，补齐技能效果、升级选项及召唤物和变形单位数据；学习面板、天赋树和已学技能详情保持完整显示。
- 保留跨职业取得技能的来源、规范 ID 和玩家 UID，支持同名、定制及待确认能力。
- 改进异形 Excel 表、多个角色表、附属笔记与原始工作簿的导入导出；保留玩家填写的数值、进阶职业、装备数量与额外能力。

## Windows 桌面

- 重复打开只唤起已有实例；主窗口和技能树预览统一处理渲染异常与加载失败。
- 新增独立恢复草稿，崩溃后可以恢复最后确认的未保存改动；恢复前不会覆盖正式存档。
- 无响应时可选择等待或从可靠恢复点重新加载。连续异常停止自动重试，并提供错误页与诊断导出。
- 新增本地故障日志、兼容渲染模式和后台资源监测，顾问或 CLI 异常按功能降级。
- 升级至 Electron 44.5.1，Windows 桌面版支持 Windows 10/11 64 位。Windows 7/8/8.1 不在本版支持范围内。

## 验证和已知范围

发布前执行完整业务门禁、真实桌面入口及打包 exe 的启动与故障恢复检查。已有技能完整详情、导入导出、多表字段与三种宽度界面回归继续验证。

开发机同序列测试中，新运行时总工作集约 812 MB，旧运行时约 516 MB；求和包含共享内存。低内存设备可尝试兼容渲染模式，切换在下次启动生效。最后一次恢复草稿写入确认之后的输入仍可能在突然崩溃时丢失。

玩家现场首次启动闪退的具体原因仍需诊断日志确认；本机 Windows 10 验收通过不代表所有显卡、Windows 11 或低内存设备均已覆盖。
