# v1.0.8058

发布日期：2026-10-11。

修复职业页血量/疲劳计算器：健壮专长不应影响疲劳值。

- 问题：勾选健壮后，疲劳值也一并被加上健壮加成（因为疲劳计算函数同样接受该参数，而此前把加成同时传给了生命与疲劳）。
- 修正：健壮加成只作用于生命值；疲劳值不再受其影响。
- 例：战舞者 20 级、体质与关键属性均 10、人类，疲劳值恒为 27（勾选健壮前后一致）；生命值仍按 2 × max(0, 当前等级 − 选择等级 + 1) 增加。
- 门禁新增断言「健壮不影响疲劳（勾选前后 FP 相同）」，防止再次回归。

## 说明
- 角色面板与导入侧的健壮算法仍为旧口径（按总等级全额计入生命，且同样把该参数传给疲劳函数），本次未改动；
- 计算器已按正确规则计算，因此勾选健壮时计算器与面板的数值会不同（已知且有意保留，待玩家反馈再评估迁移）。
