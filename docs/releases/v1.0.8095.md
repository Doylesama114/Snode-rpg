# v1.0.8095

发布日期：2026-11-03。

修复「通用天赋树 · 奇械师特性」等技能在角色面板里的效果重复显示。

## 一、现象

角色面板 → 学习 → 通用天赋树 → 奇械师特性，详情区把同一句描述渲染了 3 次：

```
描述：你获得奇械师职业的初始专长.脑力强化
你获得奇械师职业的初始专长.脑力强化          ← 重复
你的主职业等级到达6级时：你可以在兼职条件允许的情况下立即兼职奇械师职业
你获得奇械师职业的初始专长.脑力强化          ← 重复
你的主职业等级到达10级时：你可以开启子职业奇械师的三条进阶职业途径
```

`职业页/通用天赋树.html` 与数据 JSON（含 `level_upgrades`）都是正确的，问题只在面板渲染。

## 二、根因

`斯诺德跑团/panel_engine.js` 的 `formatSkillDetailHtml()`：

```js
for (i = 0; i < ups.length; i++) {
  var u = ups[i], label = ...;
  if (u.section) html += '<p><b>' + u.section + '</b></p>';   // 每条升级都输出一次
  ...
}
```

`section` 是「这条升级归属哪段描述」的分组标题，代码却对**每条升级**无条件重复输出。奇械师特性的两条升级共用同一 section，且该 section 与 `描述` 相同，于是 1 + 2 = 3 次。

## 三、修复

- 记录已输出段落的归一化集合（`描述`、`description` 行、`effects`）；
- 升级循环里，`section` 只有在**未出现过**且未被单位表覆盖时才输出；
- 同一 section 的多条升级自动归到同一标题下，只出现一次。

数据、HTML 页面、`panel_data.js` 均未改动。

## 四、影响面与验证

全量扫描 2829 条面板技能（其中 1625 条带 `level_upgrades`）：

| 指标 | 修复前 | 修复后 |
|---|---|---|
| 出现整段重复的技能 | **124 条** | **0 条** |
| 升级 label 缺失 | 0 | 0 |
| 奇械师特性 描述句出现次数 | 3 | **1** |

新增回归 `verify_panel_detail_dedup.mjs`（6 断言）并接入 `verify_all.mjs`：

- 任一技能的 section 段落不得出现超过 1 次
- 相邻段落不得完全相同
- 每条 `level_upgrades` 的 label 必须出现在详情中
- 奇械师特性：描述句 1 次 + 6 级/10 级两行完整

抽查 `生命归还`（6/12 级）、`防护箭矢`（12 级）、`旋风斩`（15/18 级）：升级行完整，仅去掉重复副本。
