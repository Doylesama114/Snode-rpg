# v1.0.8084

发布日期：2026-10-27。

补 1.0.8083 的打包遗漏。

## 问题

1.0.8083 引入的 `electron-app/portable-updater.js` **没有加进 electron-builder 的 `files` 清单**，打包后主进程 `require('./portable-updater.js')` 直接失败，应用启动即崩。CI 因此卡在 `Verify packaged desktop executable`，产物（zip / portable.json）也没上传。

## 修复

1. `electron-builder.yml` 的 `files` 增加 `portable-updater.js`
2. 新增门禁断言：**main.js 里所有本地 `require('./x.js')` 必须出现在 `files` 清单中**，防止同类遗漏再次发生

## 便携版机制（本版起生效）

```
检查 releases/latest/portable.json（OSS → GitHub 资产回退）
→ 下载 Snode-RPG-<版本>-win-x64.zip → sha512 校验
→ 解压到临时目录 → 定位含主程序的目录
→ 分离进程：ping 12s & robocopy /E /IS /IT & start 应用
→ 应用 app.exit(0) → 覆盖写入 → 新版本启动 → 校验版本 → 清理缓存
```
