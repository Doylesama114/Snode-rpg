# v1.0.8086

发布日期：2026-10-27。

**旧版本一次迁移**：让 ≤1.0.8082 的客户端也能点一下「检查更新」直接跳过来，不必手动下载。

## 背景

老版本的更新链路是「electron-updater → latest.yml → NSIS 安装器」。安装器在 `--updated` 时会先运行旧版本的卸载器；旧卸载器在目录被搬动、注册表由外部写入或文件被占用时返回非 0，

```nsis
nsExec::Exec '"old-uninstaller.exe" /S _?=$INSTDIR' $R0
${if} $R0 != 0 → MessageBox "Failed to uninstall old application files: $R0" ; SetErrorLevel 2 ; Quit
```

于是更新直接中止——这正是之前反复出现的报错。**这段逻辑在安装器侧**，所以可以从新安装器单方面修好。

## 本版改动

`electron-app/installer.nsh` 增加两个宏，覆盖 electron-builder 的失败检查：

```nsis
!macro customUnInstallCheck
  DetailPrint "customUnInstallCheck: ignoring old uninstaller failure, continue overwrite"
!macroend

!macro customUnInstallCheckCurrentUser
  DetailPrint "customUnInstallCheckCurrentUser: ignoring old uninstaller failure"
!macroend
```

`handleUninstallResult` 检测到宏后直接 `Return`，不再弹出错误、不再 `SetErrorLevel 2`、不再 `Quit`，安装器会用解压产物**覆盖写入**同一目录。残留的旧文件不影响运行。

## 旧用户的效果

| 用户状态 | 点「检查更新」后 |
|---|---|
| ≤1.0.8082（老安装器） | 下载 1.0.8086 的 Setup → 卸载旧版本失败也不再中止 → 覆盖安装 → 变成 1.0.8086 |
| 1.0.8083 及以后（便携版） | 本就走便携链路，与安装器无关 |
| 全新用户 | 直接解压 zip 使用，无需安装 |

到达 1.0.8086 之后，后续更新全部走 portable.json + zip 覆盖，不再依赖安装器。
