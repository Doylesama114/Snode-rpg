# 技能拆分速查表（2026-10-24）

> 用途：给拆分技能的人/代理当**词典**用，不解则查，不必读规则原文。
> 原则：**只放封闭词汇与定值，不放规则散文**。

## 一、关键词七类（官方定义）

### 技能与天赋（2）

| 词 | 定义 |
| --- | --- |
| 技能 | 需主动使用，必有施展时间、施展距离、持续时间、疲劳消耗四要素；职业技能槽位上限 10 |

| 项 | 内容 |
| --- | --- |
| 主要动作 | ①武器/道具攻击 ②施展需主要动作的技能 ③全速移动 ④稳定濒死 ⑤投掷物品 ⑥把主要当附赠用 ⑦回避 ⑧精密互动 |
| 附赠动作 | ①施展需附赠的技能 ②基础移动 ③跳远/跳高 ④抓放物件 ⑤切换装备 ⑥说较长的话 ⑦主动检定 ⑧瞄准部位 ⑨扑灭火 ⑩手下留情 ⑪简易交互 |

| 先攻区间 | 先锋 16+ / 中坚 11–15 / 后卫 6–10 / 殿军 1–5 |

## 五、空间

| 项 | 规则 |
| --- | --- |
| 距离 | 直线格 = 1 米，斜角格 = 2 米 |
| 自身周围 X 米 | **方形区域**，此方式下斜向也算 1 米（周围 2 米 = 5×5） |
| 射程 | 触及/徒手/近战默认相邻；远程默认 12 米 |
| 朝向 | 8 方向；默认朝向 = 上次攻击方向；正面 = 朝向为中心的 90° 扇区（3 格），背面 = 对顶 90° 扇区 |
| 落单 | 目标周围 **4 米内无己方单位** |
| 区域形状 | 扇形 N 环 / 圆形 / 3×3 / 周围 X 米 / 相邻 8 格 |
| **N 环的几何** | 以施术者格为顶点的三角形距离场：**正交**沿轴 N 行、第 d 行宽 2d−1，合计 **N²** 格；**斜向**满足 a+b ≤ N+1，合计 **N(N+1)/2** 格。同为 3 环：正交 9 格、斜向仅 6 格 |

## 六、资源与生命

| 项 | 规则 |
| --- | --- |
| 连击点 | 上限 5；基础攻击或施法攻击命中 1 次 +1 |
| 疲劳不足 | 仍可施展，FP 不为负，力竭 +1 |
| 防御层顺序 | 护盾 → 护甲值 → 临时生命值 → 生命值 |
| 护甲值 | 心灵/星界无法抵挡；钝击/雷电/力场/邪能翻倍；穿刺/挥砍/剧毒减半 |
| 临时生命/疲劳/抗性 | 不叠加，取最高 |
| 临时护盾 | 可叠加，各自独立计算 |
| **失去生命值** | **跳过防御层，但触发「受到伤害」事件** |
| **令生命值降至 0** | **直接改生命值，不触发受伤事件** |
| 击败 | 将某单位血量打至 0 或以下（≠ 死亡，≠ 处决） |

## 七、三条最容易搞错的口径

1. **0 动作 = 附赠动作**，不是“无动作”。
2. **「每场限一次」要看限定范围**：抛沙的限次只约束「回合外使用」，自身回合内不限。
3. **读到句号再判断**：整段读完才能定性，别抓半句。
4. **升级行里的动作词不是本技能的动作**。例：「5 级时你可以在自身回合花费一个附赠动作来施展熔岩护盾」——这句话在**升级行**里，说的是 5 级后可以额外花附赠动作主动施展；技能本身是**不占动作的连锁附加**（施展时间字段为空 + 条件写「仅在你施展护盾法术时生效」）。同类误判已发生 3 次（#189/#190/#191）。
