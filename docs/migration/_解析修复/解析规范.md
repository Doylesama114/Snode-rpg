# 解析规范（v2 · 2026-10-25）

> 解决「无标签延续单元格被丢弃」的问题。后续所有职业拆分前，必须先跑本规范产出的全文。

## 一、docx 的真实结构

一条技能在 docx 里不是一个单元格，而是一串：

```
技能名
前置条件：…   ← 字段
施展时间：…   ← 字段
…
描述：…       ← 字段（可能只有前半句）
[无标签单元格]  ← 效果正文的续段
[无标签单元格]  ← 召唤物属性块 / 物品属性
下一个技能名
```

**原解析器只收「字段名：」格式**，于是所有无标签续段被丢弃——这是 198 条技能描述不全的根因。

## 二、区块边界判定

| 规则 | 做法 |
| --- | --- |
| 区块开始 | 某单元格的**下一个单元格是字段**，且它自身不是字段 |
| 区块结束 | 遇到下一个区块开始，或以下跳过条件 |

## 三、哪些单元格不该收进描述

| 类型 | 判定 | 处置 |
| --- | --- | --- |
| 字段行 | 以已知字段名 + `：` 开头 | 按字段处理 |
| 技能名 | 在全局技能名集合中 | **跳过**（夹在中间的孤儿名单） |
| 名录 | 拆开后 ≥2 个且在全局名单中 | **跳过** |
| 标题 | <20 字、无标点、无数字 | **跳过** |
| 文档级总述 | 含「职责定位」 | **跳过并结束当前区块** |
| 配方/物品 | 以「配方材料：」「参考价格：」等开头 | **分类存放，不并入描述** |

## 四、三类内容分开存

```
描述        ← 技能效果正文（含召唤物属性块）
配方材料     ← 单独字段（全库 123 条）
物品属性     ← 单独字段（全库 87 条）
```

**为什么不能合并**：配方材料混进描述后，搜「泉水」会搜出一个毒药技能，污染检索结果。

## 五、已踩过的坑（按发现顺序）

| # | 坑 | 现象 | 修法 |
| ---: | --- | --- | --- |
| 1 | 字段变体未识别 | `限制：-` 被当成描述，67 条误增 | 字段表补「限制」「使用条件」等 |
| 2 | 只认已知技能名做边界 | 后面的技能被整体吞入（+1633 字） | 改为「下一个是字段即新区块」 |
| 3 | 字段被当成技能名 | 出现「加工材料：纯铁10磅」这种技能 | 区块名不能是字段 |
| 4 | 孤儿技能名被吞 | 「制裁之锤 力量祝福」进描述 | 全局名单跳过 |
| 5 | 名录单元格被吞 | 一串技能名进描述 | 名录检测 |
| 6 | 文档级总述被吞 | +4461 / +9099 字 | 含「职责定位」即停 |
