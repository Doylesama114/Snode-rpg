## 记法

| 记法 | 含义 |
| --- | --- |
| `E01(…)` | 一个效果步骤，括号内为参数 |
| `→` | 步骤先后顺序 |
| `@前` `@后` `@命中` | 时机：伤害结算前 / 结算后 / 命中后 |
| `?条件` | 该步骤的执行条件 |
| `var=…` | 该步骤产出的变量 |
| `x{…}` | 表达式（引用运行时变量） |
| `ref:关键词.名称` | 能力引用 |
| `〔3级:…〕` | 等级成长覆盖 |
| ⚠ | 该条存在待确认点，见文末 |
