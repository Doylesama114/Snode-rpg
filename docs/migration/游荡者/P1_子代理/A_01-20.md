> 依据《技能效果步骤模型规范_20261024》**v3**（30 个引擎：E01–E26 + E30 修正器 / E31 幻象 / E32 调度 / E33 分配）。
> **施展段不在此列**，一律以 `02_施展段表.md` 机器生成值为准（本文只写效果步骤那一列）。
> 逐条依据 `01_技能全文.md` 描述原文；读不出机制的写 ⚠ 并在文末「待确认」表列明缺什么。

## 待确认

| # | 技能 | 缺什么 |
| ---: | --- | --- |
| 02 | 潜行 | **C 原文缺定义**｜潜行状态的**持续时间**原文没给（只写「持续期间」，机器施展段表又写「立即」）；「感知高于 15 或具有部分特殊专长的角色仍可通过察觉检定发觉」——**检定 DC** 与「部分特殊专长」的清单都没给。属状态定义缺项，不是引擎问题。 |
| 04 | 疾跑 | **B 参数补齐**｜「同回合内多次施展，后续每次疲劳消耗翻倍」= 3·2^(n−1)，缺两样：①「本回合本技能已施展次数」运行时变量；②D92 表达式只有 `+ - * /`，没有幂。建议 E05.delta 支持 `pow()`，或补变量 `cast.countThisTurn`。 |
| 07 | 佯攻 | **C 原文缺定义**｜「取消这次攻击」的后果未定义：已消耗的动作/疲劳是否返还？这次未命中是否仍计入「本轮已施展」与连击点/攻击特效统计？现用 v3 新增的 `E10.abortDamage` 承接，但它语义是「整次伤害中止」，对「取消整次攻击」只是近似。 |
| 07 / 11 | 佯攻 / 连环奇袭 | **B 参数补齐**｜`StatusPayload.modifyTarget.filter` 只有 `keyword / name`，无法限定「**对同一目标**」（#07）、「**相邻**」（#11）、「**本战斗风格**」（#11 需 style 维度）。建议 filter 增 `targetRef` / `adjacent` / `style`。 |
| 08 | 割裂 | **B 参数补齐**｜「受到的下一次生命值回复效果在结算后减半」无载体：E26 只有 `heal / restoreFatigue / purify / ignoreHealReduction`（施术方视角），E30.target 枚举无 `healReceived`。建议 E30 增 `target='healReceived'`，或 E03 payload 增 `healMultiplier`（配 `consumeOn:'heal'`）。 |
| 12 | 袖箭风暴 | **B 参数补齐**｜「每消耗 1 点连击点提升**攻击骰的规格**（1D3→1D4→1D6，上限 1D6）」：E15 只有 `diceFloor`（点数下限），没有骰面尺寸逐级提升的字段。建议 E15 增 `dieSizeStep:{step,cap}`。 |
| 12 | 袖箭风暴 | **B 参数补齐**｜10级「每次伤害骰掷出 1 便返还 1 连击点」是**按单个骰结果计数**；表达式只有 `roll.result`（一次掷骰的合计），E01 也无逐骰输出。建议 E01 增 `perDieOut`，或 E05.delta 支持 `countDice(eq,1)`。 |
| 14 | 暗里藏刀 | **C 原文缺定义**｜「落单状态」的判定半径/条件原文未给（本技只引用状态名），E13c.radius 无从填写。属全局状态定义缺项；若战士等其它职业条目里有条文，请指过来，本批不自行补。 |
| 15 | 潜行之刃 | **B 参数补齐**｜筛选条件是「**施展限制**为必须处于潜行状态」的能力，按 cast.limits 文本匹配，而 `modifyTarget.filter` 只有 `keyword/name`。建议增 `limitMatch: string`。 |
| 16 | 死亡印记 | **C 原文缺定义**｜①「理论伤害数值」怎么取未定义（骰面上限？期望值？是否计入命中、暴击、抗性）；②「处决」的结果未定义（直接死亡 / 生命值降至 0 / 与免死·锁血·毅力如何交互）。v3 清单 §4-1 只钉了「失去生命值」一条。 |
| 16 | 死亡印记 | **B 参数补齐**｜10级「首次受到驱散效果时不会被移除」需要**驱散计数**；E03.removeOn 是枚举，无法表达「抵挡 1 次」。建议 payload 增 `dispelImmune: number`。 |
| 17 | 连击循环 | **B 参数补齐**｜「获得生效期间所消耗的全部连击点」需要**持续期内的累加器**：`consumed.combo` 是单次施展的产出，E04 的语义是「层数达阈值触发」。建议 E05/E04 增 `onEvent:'resource-spent'` + `accumulate`，或用 E32 包一层在 duration-end 结算。 |
| 18 | 快攻手 | **B 参数补齐**｜「不会提供连击点、不会触发攻击特效」（8/15 级后反转）是攻击结算的**开关**；E01/E06 都没有 `grantsComboPoint` / `triggersOnHitEffects`。 |
| 20 | 抛沙 | **C 原文缺定义**｜「前方扇形 **2 环**」的「环」不是已定义单位——§6 只定义「格=1米、斜角=2米、自身周围X米=方形」。需明确「环」= 沿扇形方向第 n 格，或给换算。 |
