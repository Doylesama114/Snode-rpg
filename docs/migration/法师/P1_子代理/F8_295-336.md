### 申请理由（为什么不能用现有引擎参数凑）

- **⟪F8-P1⟫**：#326 要的是「**已经存在的**诅咒被墙再结算一次」，不是新施加（所以不是 `E03`），也不是条件触发（`E17` 只能触发**本技能自己**写好的 `effects`，不能反查别人挂在目标身上的效果）。现有 30 个引擎里，没有任何一个能表达「按关键词找到别人的持续效果再跑一遍」。
- **⟪F8-P2⟫**：#321 的「必定失败但**仍然要掷骰**、仍可能出现大失败」这一条，`E14` 的 `autoSuccess / autoFail` 与 `fixedValue` 都表达不了（`fixedValue` 直接给结果，等于不掷骰）；#328 的「**改判**：把本次伤害替换成一个标记」既不是 `abortDamage`（那是纯免疫，不产出代价）也不是 `loseHp`（那是照扣血）。「标记 → 难度 → 致死」这套语义现在散在 `E03(state)` 与 `E14(checkType=死亡裁决)` 的字符串里，没有载体。
