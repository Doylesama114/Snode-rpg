# 法师效果步骤序列 · 批次 F1（#001–#042）

> 依据《技能效果步骤模型规范_20261024》**v3 + v3.1 + v3.2**（30 个引擎：E01–E26 + E30 修正器 / E31 幻象 / E32 调度 / E33 分配）。
> **施展段一律以 `02_施展段表.md` 机器生成值为准，本文不重写、不改写**；只有等级成长回头改写施展段时才在 `〔n级:patchCast/patchUses…〕` 里标一处（那是成长项，不是施展段本身）。
> 逐条依据 `01_技能全文.md` 描述原文，**读到自然段结束**；每一步都能在文末「原文引用」指回一个具体句子。
> 口径（用户已确认，不再当缺口报）：`1动作`=主要 / `0动作`=附赠 / 空白=纯被动；「失去生命值」= 跳过防御层但触发受伤事件；「令生命值降至 0」= 直接改生命值、不触发受伤；「下一次 X 具优势」走 `E03.payload(grantAdvantage)`；唯一性走 `cast.modifiers=[{type:'unique',key:'技能名'}]`。
> **N 环几何（D117 已确认）**：以施术者格为顶点的三角形距离场——正交沿轴 N 行、第 d 行宽 2d−1、合计 **N²** 格；斜向 a+b≤N+1、合计 **N(N+1)/2** 格。**不是半径**。本文 `radius=2环`/`3环` 即指此几何（2 环=正交 4 格／斜向 3 格；3 环=正交 9 格／斜向 6 格）。
> 记法：`→` 顺序 / `@self` `@original` `@area` 目标 / `?条件` `condition=x{…}` 执行条件 / `var=` `out=` 产出变量 / `x{…}` 表达式 / `ref:关键词.名称` 能力引用 / `〔n级:…〕` 等级成长 / `⚠` 该**步骤本身**仍有未决点（见文末待确认）。
