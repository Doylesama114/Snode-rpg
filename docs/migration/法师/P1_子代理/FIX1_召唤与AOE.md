# P1 纠错重拆 · 法师 召唤类 18 条 + AOE 豁免补正 8 条（FIX1）

> **本轮范围**：解析器修复「无标签延续单元格」后重拆。前 18 行 = 召唤/变形/制作类重写（原文现含召唤物属性块）；后 8 行 = 关键词/原文涉及 AOE 但未写豁免的补正。
> **施展段**：一律引用 `02_施展段表.md` 对应行，本表不重写施展段；仅在原文另有要求时写 `cast.modifiers` / `cast.uses` 的**增量**。
> **引擎池**：E01–E26 + E30–E33（v3/v3.1/v3.2）+ 已批准的 E34–E68（`07_新引擎申请汇总.md` 正式编号）。无自造编号。
> **口径（先用）**：
> 1. AOE 关键词隐含 **DC15 敏捷豁免，成功仍受半伤**；原文写「闪避成功」即指该豁免成功。**召唤物属性块里带 AOE 的攻击动作同样适用**（#091 长剑横扫、#406 挥击）。
> 2. N 环：`rings=N`，正交 N² 格、斜向 N(N+1)/2 格。
> 3. `1动作`=主要、`0动作`=附赠、空白=纯被动。
> 4. 「失去生命值」= `E10.loseHp`（跳过防御层、**触发**受伤）；「令生命值降至 0」= `E10.setHp`（**不触发**受伤）。
> 5. 方形区域一律 `side=N 格`（周围 X 米 → side=2X+1）。
> 6. 召唤物属性块由 `E08(template=…;statSource=…;crTarget=…)` 承载，**属性块里的每个数值都落进参数**，无一处「待补」。
> **记法**：`→` 结算顺序；`?条件`；`x{…}` 表达式；`out=` 产出变量；`〔N级:…〕` 等级成长覆盖；`⚠A1` 见文末②。
