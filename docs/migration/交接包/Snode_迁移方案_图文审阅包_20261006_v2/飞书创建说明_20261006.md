# 飞书创建步骤

> 本次文档已创建：[打开飞书审阅版](https://lcnnkviu5vj0.feishu.cn/docx/RHBcdisuGop0SzxZfarcJhuxnLc)。以下命令供后续使用；需要新建另一份文档时才运行创建命令。

本机已安装官方Lark CLI 1.0.97，程序在D盘；项目的CLI配置目录也在D盘。首次使用需要完成应用配置和个人账号授权。

## 1. 配置应用并登录

在PowerShell中设置本次进程的目录：

~~~powershell
$env:TEMP = 'D:\dsh-temp'
$env:TMP = 'D:\dsh-temp'
$env:LARKSUITE_CLI_CONFIG_DIR = 'D:\dsh-home\lark-cli-snode'
~~~

初次配置使用以下命令，在它给出的官方网页完成配置。已有配置时先检查，不重复新建：

~~~powershell
& 'D:\dsh-tools\lark-cli\node_modules\.bin\lark-cli.cmd' config init --new --brand feishu
~~~

登录仅请求文档和云空间相关领域。命令返回授权页面后，由账号本人在浏览器确认；成功后检查状态：

~~~powershell
& 'D:\dsh-tools\lark-cli\node_modules\.bin\lark-cli.cmd' auth login --domain docs,drive
& 'D:\dsh-tools\lark-cli\node_modules\.bin\lark-cli.cmd' auth status
~~~

## 2. 创建个人云空间文档

进入包含导入稿、配图和技术附件的目录。命令使用用户身份，创建普通飞书云文档：

~~~powershell
Set-Location 'D:\Download\scholar-agent-main\docs\migration'
& 'D:\dsh-tools\lark-cli\node_modules\.bin\lark-cli.cmd' docs +create --as user --parent-position my_library --doc-format markdown --title 'Snode 一期迁移方案（图文审阅版 v2）' --content '@./Snode_一期迁移计划_飞书导入稿_v2_20261006.md'
~~~

若在解压后的审阅包运行，进入该包根目录即可；导入稿和资源相对路径不变。保持同一个配置目录和登录用户。

本地图片使用@./路径，CLI会上传并插入正文；技术附件也随导入稿上传。HTML的Base64图片地址不适用于这一导入命令。

## 3. 回读并检查

保存创建结果中的document_id与url，检查warnings，再回读：

~~~powershell
& 'D:\dsh-tools\lark-cli\node_modules\.bin\lark-cli.cmd' docs +fetch --as user --doc '这里填返回的文档ID或URL' --detail with-ids
~~~

核对标题、8个主体章节、4张图和技术附件。最后在飞书里查看排版，并按需要授予合作开发者阅读或评论权限。

超时或结果不明确时先核对是否已经创建，不直接重复创建同名文档。
