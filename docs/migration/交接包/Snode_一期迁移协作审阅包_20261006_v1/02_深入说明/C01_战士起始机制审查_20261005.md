## 武器专精的六项机制

下表描述六个可选类别的机制。F62已确认取得时只选一个类别，角色仅获得该项，且使用对应武器时才生效。取得选择与当前装备条件分别保存。

| 武器类别与来源 | 原文效果 | 战斗机制需求 |
| --- | --- | --- |
| 剑 body[67] | 每自身回合一次，近战伤害骰为1可重掷，接受新结果 | 伤害骰的单骰处理、使用次数、重掷轨迹；沿用F17，避免整组重骰 |
| 斧 body[68] | 暴击率+1 | 扩张自然暴击骰面；不把最终命中总值20当暴击 |
| 锤 body[69] | 对重甲或天生护甲目标，近战每颗伤害骰不低于4 | 目标特征谓词、每骰最低值修订；不能用“护甲余额>0”代替重甲／天生护甲 |
| 长柄 body[70] | 可单手持有 | 装备持用约束覆盖，不是攻击伤害修正 |
| 弓箭 body[71] | 攻击命中检定+2 | 条件武器命中修正，不能当普通熟练项被上限1截掉，也不加到法术命中 |
| 简易武器 body[72] | 每场一次，用附赠发起基础攻击，不能施展技能 | 附赠预算、每场次数、基础攻击与施展能力类型区分 |

这些机制将复用于其他来源。武器类别、效果取得来源、作用条件和次数作用域都要在记录中可见，不能把它们写进战士专用攻击函数。

## 本轮答复及规范映射

F61用户原答：猛击12级改为总共附加两次额外力量调整值，本身的平a的伤害是武器骰+力量调整值，使用12级之前的猛击是武器骰+2*力量调整值，在12级时变为武器骰+3*力量调整值。

采用：能力额外部分是一次→两次的替换。本题力量平A示例下，猛击12级前为武器骰＋2×力量调整值，12级起为武器骰＋3×力量调整值。保留原件“还会再”措辞，通过用户确认映射消除叠加歧义；相对防御层的位置不由此推导。

F62用户原答：选一个类别，只获得该增益，并且只有使用对应武器时才生效。

采用：武器专精选择事实、实际武器类别和增益条件三者关联。只使用对应武器但没有取得该类专精，不会获得增益；未选类别不能自动生效。F63及补例确认不乘暴击，先合并再经抗性与防御，不要求先造成生命损失。

F63用户原答：不乘暴击，因为写明了是造成伤害后额外附加力量调整值；损失0。

补例用户原答：损失为1。补例输入为普通攻击8、额外力量3、抗性10，无其他防御，非暴击。

规范步骤：普通攻击及其正常属性部分先按适用暴击计算，猛击额外力量不乘暴击；之后把额外部分并入攻击伤害，再处理抗性、护盾、护甲、临时生命、生命。原例损失0，补例8＋3−10＝1。这里没有“普通攻击先造成生命损失”的触发前提，原文也不因此被直接改写。
