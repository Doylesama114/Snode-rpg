## 学习与成长不能混成施展资格

F73明确数量包括天赋和免费初始，跨职业取得只有按其规则会计算风格时才计入；未习得风格为0，未写“之一”的最多／最少不得靠并列满足。补例明确并列最低不满足“不是最少”，因此该否定条件用count>min，不能取反“唯一最少”。风格顺序仍按F55；初始可以不参与顺序却参与数量，两个解析结果必须分开。

本次游玩、当前战斗、角色自身回合、公共轮次、本阶开启后、剧情年数与休息周期各有不同锚点。剧情两年不能按现实客户端日期相减；当前已有十次攻击也不能自动拿来满足“本位阶及后”的十次。没有历史数据时留主持认可的事实证据，不默认为0或已满足。

武器掌握追加的是初始专精中的增益，不是重新学第二个同名技能。初始选择仍一类，后续追加用独立来源和奖励凭据，汇总为已获类别集合。破敌战戟前置查询这个集合，不能只查最初那一项。F68已确认12级首次学习即追加基础、5级、10级三项奖励，分别领未拥有类别。

二连斩升级三连斩的普通职业路径，建议保留同一持有UID、获取记录和栏位，用解析出的升级形态显示新名称。目录两个源卡都保留；普通直接学习、跨来源直接取得、以及永久禁学是否覆盖整个家族未由本条确定。家族身份不能自动扩大F59的同名禁学范围。

## 对引擎的新增要求

| 设计对象 | 必须表达的内容 | 来源例子 |
| --- | --- | --- |
| ActionResolution与AttackSegment | 根行动、分段ID、固定目标、命中与未中、父事件、逐段合法性及反应窗口 | 二／三连、顺劈、姿态再攻 |

| PairScopedEffect | 提供者、受益者、对手、攻击类型、次数和期限，不能改全局角色抗性／AC | 碾压忽视防御、破敌双向增减 |

| MaxDamageProjection | 理论输入、暴击状态、防御取值、严格／包含等号比较与可见性 | 致死打击 |
| TypedHealthBenefit | 治疗、溢出、临时生命、上限增加分别记录 | 巨人打击 |
| EffectSnapshot与CopyPolicy | 当前有效收益、数值与计数快照、剩余期限、维持者／受益者／来源、媒介和冲突 | 葬送 |
| DefeatProtectionPolicy | 濒死、死亡、处决、不败、毅力的作用阶段和具体转换 | 愈战愈勇18级 |
| SpatialResolution | 路线、扫掠集合、落点、击飞与坠落步骤、独立的效果分支 | 巨龙冲锋、双跳 |

一个能力可以组合多个对象。新增角色或职业使用统一ActorState和来源定义，不建立人物专用class，不按技能名称在角色类中堆条件分支。当前这些对象仍是设计候选。

“完成行动”要等根技能及其后继事件结算后再判断。致死打击处决成功产生的主要额度，应在区间结束判断前入账；不能先看预算归0就结束回合。免费基础攻击许可与主要额度是不同事物，下一回合许可也不能提前花在本回合。自主结束区间、免费能力选择和新增额度的交互在关键交互设计中继续验证。

F71明确这是转移当前收益：保持当前数值、剩余层数和时长，原目标失去，不重新按自身数值施展。不能复施过去治疗或复制整份角色／库存。仅本能力的媒介暂不作生效检查，C81一般定义保留。新持有者的毅力／个体永久收益仍按原文战末到期；原目标还活时是否恢复永久收益，DM决定，不能自动长期删除或自动恢复。
