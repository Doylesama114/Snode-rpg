# Snode 美术与界面方向

版本：v0.2 评审稿，2026-10-02。当前首页用于确认基础视觉，不代表登录、建卡、协作或经济功能已经实现。

## 推荐方向：墨色与旧金

采用克制的奇幻叙事风格：深墨色承载界面，暖白负责阅读，旧金强调主要行动，雾青连接风景与信息层。首页以一幅原创风景和中文衬线标题建立世界感；角色表、资料库和管理页面延续颜色与排版，使用稳定、清晰的纯色信息区。

这是从参考产品中提炼出的设计建议。视觉方向应在首页评审后再作为后续页面的基准。

## 参考与取舍

调研包括 EchoVoyage 的设计文档与实际 CSS，以及以下产品的官网画面、界面示例或官方教程。以下内容是对已观察界面的设计分析，不是对产品整体优劣的排名。

| 参考 | 观察与借鉴 | 在 Snode 中的落点 |
| --- | --- | --- |
| [EchoVoyage](https://github.com/Usokyun/EchoVoyage/blob/master/docs/design/gameplay-ux.md) | 深色舞台、暖金行动、衬线标题、细边框与留白；界面信息服务于故事体验。 | 延续气质，金色略降饱和；中文标题使用宋体类衬线字体，正文使用系统黑体。 |
| [Owlbear Rodeo](https://www.owlbear.rodeo/) | 官网使用大幅场景与少量入口；界面示例让画布居中，工具围绕内容摆放。 | 首页只设一个主要行动，导航保持精简。未来工作区优先呈现当前任务需要的信息。 |
| [Roll20](https://roll20.net/) | 官网使用高辨识度强调色和明确的主要入口，展示角色表、地图与资料的联系。 | 主按钮和次要文字链接区分明显；角色与规则的入口使用直接可理解的名称。 |
| [Foundry VTT 官方界面教程](https://foundryvtt.com/article/tutorial/) | 场景控制、聊天、角色、物品与日志有明确的空间分工。 | 未来按角色、团和物品组织信息。第一版首页保持简单，复杂工具随业务页面增加。 |
| [Alchemy](https://alchemyrpg.com/) / [场景说明](https://help.alchemyrpg.com/en/articles/9821311-creating-a-scene) | 暗色界面配合场景画面形成氛围；场景视觉、声音与叙事信息分层。 | 首页用风景建立情绪；实际角色数据保持清晰，不将文字和表单直接压在复杂插画上。 |

Snode 一期以角色管理为核心，因此需要兼顾奇幻气质与长时间阅读。首页可以有叙事氛围，日常操作页应让名字、数值、规则和权限更容易辨认。

## 基础颜色

颜色统一维护在 [styles.css](../apps/web/src/styles.css) 的 CSS 变量中。

| 变量 | 色值 | 用途 |
| --- | --- | --- |
| `--color-background` | `#080C10` | 全局深墨背景 |
| `--color-surface` | `#11191F` | 信息区和浮层背景 |
| `--color-text` | `#F0ECE2` | 暖白主文字 |
| `--color-muted` | `#9AA7AF` | 辅助文字 |
| `--color-accent` | `#DFBB7D` | 旧金主按钮、当前选择与关键标题 |
| `--color-mist` | `#73918F` | 雾青装饰与风景衔接，不作为小号正文色 |
| `--color-line` | `rgb(216 229 231 / 12%)` | 分隔线与结构边界 |

金色集中用于主行动和关键层级，不覆盖整页。成功、警告、错误等业务状态的颜色，待对应功能设计时统一补充；它们不承担品牌装饰。

## 字体、形状与动效

- 中文标题：Songti SC / Noto Serif CJK SC / Noto Serif SC / SimSun；英文品牌：Georgia。字体从系统取用，不依赖远端字体加载。
- 正文、标签、按钮：系统无衬线字体；章节标签使用 SFMono-Regular / Consolas 等宽字体。英文叙事副标题使用 Georgia 斜体。正式表单与规则正文建议 14–16px；小号文字仅用于补充信息。
- 结构：直角或小圆角、细分隔线、大留白；功能信息按内容组织，避免把每段说明都包进卡片。
- 图标：几何、单色、细线。当前六边形罗盘为品牌方向草稿，箭头用于真实链接。
- 动效：仅保留 180ms 的颜色与轻微位移反馈；尊重减少动态效果的系统设置。
- 交互：可见的键盘焦点、跳转正文入口、语义化标题和导航；手机保留主要入口，横向不溢出。

## 首页结构

首页包括简洁导航、风景主视觉、一个指向一期计划的主入口、项目介绍入口、三段一期方向与页脚。所有入口均指向实际的页内内容或既有开发文档；首页明确标记正在建设中。

## v0.2 精修依据

进一步对照了 EchoVoyage 的 [首页实现](https://github.com/Usokyun/EchoVoyage/blob/master/apps/web/app/page.tsx)、[首页样式](https://github.com/Usokyun/EchoVoyage/blob/master/apps/web/app/globals.css) 与 [游戏界面样式](https://github.com/Usokyun/EchoVoyage/blob/master/apps/web/app/game/game.module.css)。此次重点借鉴实际排版与层级：衬线主标题、斜体叙事强调、等宽元信息、低对比度径向光晕，以及场景与辅助信息之间的清晰边界。

- 将内容统一到 1280px 的版心，导航、标题、章节和页脚共用对齐线；主标题缩为两行，中文与英文叙事使用不同的字号和节奏。
- 画面以取景框、角标和低对比度星盘定位，边缘渐隐到深色舞台；装饰 SVG 由代码绘制，无交互含义。
- 介绍区以细分隔线组织三个栏目，统一编号、等宽英文标签、中文衬线小标题和正文间距。
- 手机使用文字在上、场景在下的构图，避免把阅读内容压在复杂建筑画面上；窄屏裁切装饰，保持正文与链接完整可用。
- 悬停只改变强调色、边框、细线和箭头；正文可以选择复制，键盘焦点和减少动态效果设置继续生效。

评审重点：深色是否适合项目气质、旧金是否作为品牌强调、宋体标题是否保留、主视觉的奇幻程度是否合适。确认后再将这些规则扩展到建卡与角色管理页面。
