# 角色管理候选核心与本机界面预览

状态：实施0候选核心已接入实施1首个网页切片，待共同评审。
基于 Snode main `929cd8c`，本地分支 `codex/character-management-implementation0`。
正式公共 ABI、完整 CharacterData 与生产 API/数据库尚未定版，旧存档和 Excel 迁移暂缓。

## 本轮可操作范围

保留原首页，主导航增加“角色档案”，入口为 `#/characters`。
列表可搜索、打开角色，或新增一份本机档案；新增不执行合规建卡。

面板安排六个区：资料与经历、当前数值、成长与能力、装备与物品、手工状态、历史快照。
本轮实现资料/经历、已注册数值、只读历史；成长/能力、装备/资产、结构化手工状态明确标为待接入。
预览采用匿名示例，记录仅保存在当前浏览器，同一浏览器同一 origin 重开可恢复。
页面持续显示“本机开发预览”，没有登录、跨设备或云保存能力。

输入后台节流约 600ms 保留本机草稿，点击“保存正式记录”才更新本机正式记录并新增快照。
普通关页前提示未保存修改；隐藏/离开触发尽力保留，突然断电/进程终止不能保证最后未确认的输入落盘。
浏览器清理站点数据会清除这些预览数据。本机存储不是云端备份。

## 代码位置和边界

- `contracts.ts`、`validation.ts`：管理投影、白名单编辑、回执与严格运行时校验。
- `editor.ts`：纯候选编辑控制器；没有 DOM、HTTP、数据库、战斗或资产操作。
- `draft.ts`：草稿检查点校验；允许保留无效原输入，拒绝错误基线/身份/命令关联。
- `adapter.ts`：共同角色文档、已验证身份及事务边界，生产适配尚未实现。
- `apps/web/src/features/characters/CharacterWorkspace.tsx`：列表、编辑、历史与统一对话框。
- `editor-runtime.ts`：界面会话与草稿、提交、恢复、冲突协调。
- `local-service.ts`：独立本机开发适配器；正式服务通过 CharacterService 端口替换。
- `characters.css`：沿用深墨/暖白/旧金方向，含手机布局和可见焦点。
- 三份核心测试与 `apps/web/test/characters.browser.test.mjs`：协议/恢复与匿名浏览器验收。

`ManagementView` 是共享角色文档的只读投影，不是完整 CharacterData。
本机适配器存储投影仅用于匿名预览，禁止据此设计生产角色表。
`packages/contracts`、真实 API 与数据库 Schema 未修改。
另一工作线拥有定义引用、职业进度、能力获取与规则结构；此处无人物/职业子类，
不硬编码七阶、领域表、学习奖励或战斗公式。多团和资产策略未定版。

## 保存 草稿与恢复行为

1. 正式保存只发送注册字段的明确改动，不包含拥有者、权限、钱包或库存。
   UI editable 只是显示能力，contextKey 只是预览隔离，不构成服务认证。
2. 0、清空、无效原文和未提供分别处理，不静默修正、截断或夹上限。
   当前预览只校验数字格式；游戏范围与效果等待规则提供方接入。
3. 点击保存冻结命令及提交时输入，保存期间的新输入仍是未提交草稿。
   命令带 submittedDraftVersion；服务回执需匹配命令/角色/提交版本。
4. 第一次派发前必须保留含在途命令的检查点。保留失败不会发送正式请求。
   结果不明时保留并核实原命令，不新建替代命令。
5. IndexedDB 单事务写当前记录、不可变快照和命令结果；相同命令不重复产生修订，
   相同编号/不同内容拒绝。所有能力/字段白名单仅为匿名预览策略。
6. 草稿按随机会话/草稿 ID 分开，条件写入和确认不倒退。
   放弃仅作用于本页草稿，用版本条件和墓碑拒绝迟到写入。
7. 重开先显示可恢复草稿，用户选择后复制到新会话并保留原检查点。
   只有副本耐久后标记该来源版本已复制；来源页面的新写入仍可继续。
   有在途命令先幂等核实，再比对最新正式修订。
8. 版本冲突保留旧基线及输入，不相交字段可合并；竞争字段需明确选择。
   字段失去编辑权限的待审输入及冲突视图也随草稿保留，恢复后仍可明确核对。
9. 读取、正式提交、草稿保留有各自错误；一个成功确认不会掩盖另一个失败。
   历史详情只读；长正文和换行完整保留，名称/故事按 React 文本显示。
10. 离开支持继续编辑、保存后离开、放弃本页草稿。
    在途命令未核实时不提供直接放弃；提交后新增输入仍然需要保存或明确放弃。

候选传输预算为 ID 128、名字 256、故事 65536 个 JavaScript 字符单位；
这是软件预算，不是游戏规则，不截断原输入。本机草稿容量与保留期限尚未制定，
正式云端草稿、账号切换、DM 撤权和跨设备并发仍需生产服务验收。

## 启动与验证

需要仓库指定 Node 24、pnpm 11.9.0。只预览网页无需数据库：

```sh
pnpm install --frozen-lockfile
pnpm --filter @snode/web dev
```

打开 http://127.0.0.1:5173/#/characters。

```sh
pnpm test:characters
pnpm typecheck:characters
pnpm check
pnpm exec playwright install chromium
pnpm test:characters:browser
```

浏览器验收自行启动并关闭 localhost:5194 Vite 与无头浏览器，
不操作用户桌面浏览器。可用 PLAYWRIGHT_CHROMIUM_EXECUTABLE 指向已有浏览器二进制；
CHARACTER_SCREENSHOT_DIR 可选保留匿名截图。缓存/临时目录遵循本机落盘政策。
CI 在 pnpm check 后安装 Chromium 并运行浏览器验收；远程 CI 尚未执行。

本轮最终验证结果和实际工具版本记录在同一角色管理审查报告。
生产能力仍待共同契约评审、已验证身份、完整文档适配、服务授权及事务接入；
这份本机预览不代表管理 ready 或一期完整 ready。
