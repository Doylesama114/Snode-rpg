## 三、已确定的关键决策（摘要）

**范围与身份**
- 一期范围 = 资料库（技能 + 职业，含 590 条进阶途径）；不做建卡与面板
- 身份 = 职业/领域 + 风格 + 阶位 + 形态 + 名字 + 稳定 ID；名字不是身份（333 个名字跨文档重复）
- 形态采用官方定义：技能四要素齐备，天赋无四要素
- 进阶途径门限数据已经是结构化表格（590 条），解析成本低

**规则变更（2026-10-23 公告）**
- 标识三身份：展示继续、学习门槛取消、进阶门槛保留
- 技能数据一律不动，等全职业技能表更新到位；只关学习端检测
- 规则与数据分离，支持只发规则不发数据
- 文档新增一节，正面回答合作开发人的提问

**战斗引擎**
- 技能不是最小实现单位，基本引擎才是；组合可实现的不单独造引擎
- 引擎规划以人工为准，禁止猜测实现逻辑（已因此推翻一次分类错误）
- 资料库是战斗数值唯一来源，不另建能力卡数据集
- 按职业推进、先难后易；游荡者作为第一个摸底对象
- 分类必须读描述原文，关键词只作索引

**架构**
- 三张核心表起步：技能表 / 来源表 / 发布批次表；历史靠批次，不建逐条版本表
- 状态三种：草稿 / 已发布 / 停用（停用保留占位可回退）
- 导入 = 解析成草稿 + 异常清单 + 人工逐条确认
- 战斗状态是显式状态，以「实例」为单位；DM 开关本期预留接口
