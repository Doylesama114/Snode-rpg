# 游荡者 · 基本引擎清单（2026-10-24 · P2 已评审）

> 判据（D36）：能由复数基本引擎**组合**实现的技能，不单独造引擎；只有参数化不出来的才立新引擎。
> 依据：《战斗数值规则参考_20261024》+ 83 条描述原文 + 官方关键词体系。
> **P2 评审结论**：整体划分认可；覆盖 ≤4 的单元全部保留不动；E13 已拆为 E13a/b/c；E22 保留但标记非战斗。

## 一、三层结构

共 **26 个实现单元**：

| 层 | 数量 | 说明 |
