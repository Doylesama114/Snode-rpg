# 战士效果步骤序列 · 批次 W1（#001–#040）

> 依据《技能效果步骤模型规范_20261024》**v3 + v3.1 + v3.2**（30 个引擎 E01–E26 + E30–E33），以及《法师 07_新引擎申请汇总》**已批准的 E34–E68**（本文用到 E51）。
> **施展段一律引用 `02_施展段表.md` 机器生成值**，本文不改写、不重填；行内 〔主要·近战·1FP·立即〕 只是把该表同一行的三列**逐字压缩转抄**，便于对照（表里写 `1动作(主要)`/`近战`/`1`/`立即`）。只有成长回头改写施展段时才写 `〔n级:patchCast/patchUses…〕`。
> 逐条依据 `01_技能全文.md`（解析 v2）描述原文，**读到自然段结束**；每步都能在文末「四、原文引用」指回一句原句。
> 已确认口径（直接用，不当缺口报）：`1动作`=主要 / `0动作`=附赠 / 空白=纯被动；AOE 关键词隐含 DC15 敏捷豁免、成功仍受半伤；N 环几何（正交 N²、斜向 N(N+1)/2）；方形区域写 `side=N 格`（周围 2 米=5×5）；失去生命值=跳过防御层但触发受伤；令生命值降至 0=直接改生命值不触发受伤；「下一次 X 具优势」走 `E03.payload(grantAdvantage)`；唯一性走 `cast.modifiers=[{type:'unique',key:'技能名'}]`；伤害类型照 33 种枚举填。
> 记法：`→` 顺序 / `@original` `@area` `@self` 目标 / `condition=x{…}` 执行条件 / `out=` 产出变量 / `x{…}` 表达式 / `〔n级:…〕` 等级成长 / `⚠` 该**步骤本身**仍有未决点（见文末待确认）。
