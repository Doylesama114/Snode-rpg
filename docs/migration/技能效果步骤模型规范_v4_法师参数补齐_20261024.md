## 二、三处最容易漏、影响最大的

| # | 项 | 影响 |
| ---: | --- | --- |
| 1 | **E03.payload 是最大瓶颈**（118 处提及） | 状态的载荷要能表达「禁止什么、替代什么、改写什么」，现在的载荷太窄 |
| 2 | **E17.event 枚举不全**（38 处） | 大量触发式效果挂在不存在的事件上 |
| 3 | **`cast.uses.onlyWhen` 还要能叠加额外成本** | 「每场一次，且要用反应动作在他人回合使用」这种复合限制，v3.1 只给了前半段 |

## 三、口径统一（与参数同等重要）

| 项 | 统一为 |
| --- | --- |
| 方形区域 | `side=N 格`（周围 X 米 → side=2X+1） |
| N 环 | `rings=N` + 正交 N² / 斜向 N(N+1)/2 |
| ⚠ 标记 | **只标「执行器按现文得不出唯一结果」**；A/B 类不占 ⚠ |
| 复用率 | 同时报「按技能条数」与「按引擎步数」 |
| 新引擎编号 | 正式编号 E34–E68，拆分期间用批次前缀临时标签 |
