### 乙、规则语义 —— 已明确

| # | 结论 |
| ---: | --- |
| B1 | **优劣六档体系**：①优势＝骰2取高 ②劣势＝骰2取低 ③**极大优势＝骰3取最高** ④**极大劣势＝骰3取最低** ⑤**绝对优势＝骰4取最高** ⑥**绝对劣势＝骰4取最低**。触发示例：攻击**失能**状态的敌人，攻击命中有极大优势 |
| B1a | **团队幸运值** = 团队内所有角色幸运调整值之和。≤-1 且 >-3 → 事件检定**劣势**；≤-3 且 >-5 → 事件检定**极大劣势**；≤-5 → **绝对劣势** |
| B2 | **指向性效果** = 需要选择目标才能释放的效果。AOE 不算指向性；但**选定多个目标释放的仍算指向性** |
| B3 | 额外防御等级 = 附加在角色基础防御等级之外的防御等级。护甲值与结算顺序、伤害抗性详见 GPT 工作文档 |
| B4 | **防御等级是数值**（非层数） |
| B5 | 体型分级：**小型／中小型／中型／中大型／大型**。大型相对中型即「超过两个规格」。依据：冒险者创建流程的种族创建栏 |
| B6 | 生物类型免疫表：见**召唤师契约生物**及其它召唤物数据 |
| B7 | 重伤／恶性创伤：见帮助页异常状态规则 |
| B8 | 豁免种类体系：详见 GPT 工作文档 |
| B9 | 暴击判定：详见 GPT 工作文档 |
| B10 | 区域形状详见 GPT 工作文档。**重要补充**：「自身周围 X 米」是**方形区域**，以此方式计算距离时**斜向也算 1 米**（例：自身周围 2 米 = 5×5 正方形）。注意与「斜角格 2 米」并存，二者适用场景不同 |
| B11 | **无视单位碰撞体型** = 移动不被其他单位阻挡，且可停留在其他单位所在格内。默认规则：不同单位不可同格，移动会被阻挡 |
| B12 | **连击点上限 5 点**。基础攻击或施法攻击**命中 1 次 +1 点**；基础攻击含普通近战、普通远程，以及用技能进行的近战/远程攻击 |
