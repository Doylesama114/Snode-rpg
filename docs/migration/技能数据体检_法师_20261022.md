## 3. 五个对结构有直接影响的发现

### 3.1 升级行藏在描述正文里（251 / 422 条 = 59%）

描述是"现象描述 + 效果 + 升级行"连成一段，只靠空格分隔。等级点分布：5 级 58、10 级 72、12 级 69、15 级 93、18 级 46，另有 3/6/8/9/14/16/17/20 零星。

样例：

```
塑能箭: 你的法师职业等级到达5级时 | 你的法师职业等级到达8级时
预知梦: 你的法师职业等级到达6级时 | 到达12级时 | 到达18级时
```

**结论**：升级行必须切出来成为独立数组，否则角色到 12 级时无法只显示对应文本——这就是"可调用性"的硬要求。

### 3.2 单位（召唤物）数据被写进散文，没有表格

3 条：`武道家之手`、`附魔武器·赋予生命`、`召唤骷髅士兵`。防御等级、生命值、移动速度、动作选项全在描述文字里。

**结论**：这是旧站"召唤物只剩摘要"的根因——**没有表格可解析，不是解析器偷懒**。第一版应保留原文 + 弱解析几个关键数字（防御等级 / 生命值 / 速度），解析不出的原样留着。

### 3.3 标识是逐点着色，法师 55% 多色

234 / 422 条多色。样例：`火球术` = 红 + 蓝，`冰霜新星` = 蓝 + 白。

**结论**：标识必须是"逐点 (颜色, 顺序)"的数组，不能压成一个颜色值。法师没有分组斜杠 `/`（那是奇械师"费用：●●/●"的写法），分组字段仍要留。

### 3.4 纯被动天赋的字段极少

最少的两条只有 关键词 + 描述（`预知梦`），另有 4 条只有 4 个字段。旧站若按"主动技能"模板强校验，这类会被误判为残缺。

**结论**：校验规则要按"形态"分流：主动技 / 天赋 / 图纸，各有各的必填集。绝不能一套规则卡全部。

### 3.5 法师没有同名问题 —— "先做法师"需要补一个样本

同名重复（灵龟守护 主动技 vs 天赋、毒性蔓延 两条来源）出现在猎人、召唤师、谋士，**法师 0 组**。

**结论**：法师能压测"量、风格×阶位、多色标识、单位块、图纸"，但压不到"同名异源"这条最难的路径。建议法师跑通后，立刻补一份**猎人**（同名 3 组）做对照，再批量。
