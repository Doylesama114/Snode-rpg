## 1. 检定体系

### 1.1 熟练项检定（剧情向）

| 项 | 规则 |
| --- | --- |
| 公式 | 掷骰点数 + 熟练度加值 + 属性调整值 = 检定结果 |
| 无该熟练项 | 掷 1 颗 D12 |
| 有该熟练项 | 掷 1 颗 D12 + 1 颗 D8 |
| 色彩骰 | 每场游玩共有 8 颗不同颜色的 D8（勇猛/协调/体魄/智慧/机敏/卓越/强韧/运势），可在一次熟练项检定中投入任意数量，选其中一颗计入 |
| 专业熟练项 | 流程与基础熟练项一致，可在合理情况下附加到基础熟练项的加值中 |

### 1.2 其他检定类型与骰型

| 检定类型 | 骰 |
| --- | --- |
| 先攻检定 | D20 |
| 对抗检定 | D20 |
| 属性检定 | D20 |
| 豁免检定 | D20 |
| 事件检定 | **D100** |

公式统一为：掷骰点数 + 对应加值 = 检定结果。

### 1.3 难度档

| 难度 | 程度 |
| ---: | --- |
| 5 | 轻而易举 |
| 10 | 容易 |
| 15 | 中等 |
| 20 | 困难 |
| 25 | 极难 |
| 30 | 几乎不可能 |

事件检定结果区间：1–24 较好的机遇 ／ 25–49 普通的遭遇 ／ 50–74 较坏的遭遇 ／ ≥75 极度危险的境地。

### 1.4 优劣势六档（用户 2026-10-24 确认）

| 档位 | 掷骰方式 |
| --- | --- |
| 优势 | 骰 2 颗取高 |
| 劣势 | 骰 2 颗取低 |
| **极大优势** | 骰 3 颗取最高 |
| **极大劣势** | 骰 3 颗取最低 |
| **绝对优势** | 骰 4 颗取最高 |
| **绝对劣势** | 骰 4 颗取最低 |

- 攻击处于**失能**状态的目标，攻击命中有极大优势。
- **团队幸运值** = 团队内所有角色幸运调整值之和：
  - ≤ -1 且 > -3 → 事件检定**劣势**
  - ≤ -3 且 > -5 → 事件检定**极大劣势**
  - ≤ -5 → **绝对劣势**

## 2. 战斗流程与行动经济

### 2.1 六个阶段（help.html 战斗流程图）

| 时刻 | 内容 | 归类 |
| --- | --- | --- |
| 玩家进行先攻检定 | 投 1 颗 D20，点数 + 敏捷调整值 = 先攻时序值 | 战斗开始的准备工作 |
| 根据先攻时序值决定战斗区间 | 所有玩家投先攻后排序；NPC 先攻为固定值 | ↑ |
| 轮次开始阶段 | 结算战斗环节中的公共事件，通常是延时性负面效果 | 战斗环节中的流程（循环） |
| 同一区间的玩家穿插执行各自行动 | 主要动作／附赠动作 | ↑ |
| 轮次结束阶段 | 结算公共事件 | ↑ |
| 战斗结束 | 一方被击败或剧情到达某个节点 | 最终结果的结算 |

### 2.2 先攻四区间

| 区间 | 先攻检定结果 |
| --- | --- |
| 先锋席 | 16 – 20+（不存在大成功） |
| 中坚席 | 11 – 15 |
| 后卫席 | 6 – 10 |
| 殿军席 | 1 – 5（不存在大失败） |

### 2.3 动作清单

**主要动作（8 条）**：①用武器或道具攻击 ②施展需主要动作的技能 ③全速移动（不可与 ★ 行动同回合）④稳定濒死角色伤势 ⑤投掷物品 ⑥将主要动作当附赠动作使用 ⑦回避（本回合移动不被借机攻击）⑧较精密的互动。

**附赠动作（11 条）**：①施展需附赠动作的技能 ②★基础移动 ③★跳远／跳高（每个自身回合限一次）④抓取或放下物件 ⑤切换武器／防具／道具 ⑥说一段较长的话 ⑦主动进行属性或熟练项检定 ⑧瞄准特定部位 ⑨扑灭火焰 ⑩使随后的行动手下留情 ⑪较简易的交互。

**反应动作**：可在自身或其他角色回合使用，不消耗主要／附赠动作，**每场战斗限 3 次**（即便拥有更多反应能力）。

### 2.4 敌人阈值

- 敌人不投先攻，具有固定战斗区间（通常在同区间玩家之后行动）。
- 玩家每执行并结算一次行动后立即更新：命中／控制成功／有效操作 → 阈值小幅提升；失手／（被）豁免失败／无效操作 → 大幅提升；检定大失败 → 直接顶峰。
- 阈值达上限时立即清空，该敌人在当前玩家这个动作结束后插入一次行动；同一轮次已触发过则本轮不再触发。

## 3. 伤害结算与防御层

### 3.1 结算顺序（战士「全副武装」原文）

> 每当你受到伤害时总是会**优先结算护盾数值，其次是消耗你的护甲值，最后是临时生命值和你本身的生命值**。

护甲值的伤害类型修正（同条原文）：

| 情况 | 效果 |
| --- | --- |
| 心灵、星界类伤害 | 护甲值**无法抵挡** |
| 钝击、雷电、力场、邪能 | 护甲值消耗**翻倍** |
| 穿刺、挥砍、剧毒 | 护甲值消耗**减半** |
| 长休 | 未用完的护甲值**消散** |

### 3.2 叠加与取最高（help.html 特别注释「关于临时数据」）

- 临时生命值、临时疲劳值、**临时伤害抗性**：不叠加，多个同类效应**取最高值**（F27 已确认取最高，撤回 8+10=18 的叠加说法）。
- 临时护盾值：**允许叠加**，但每个护盾**独立计算**。

### 3.3 取整与护甲余额（F28）

- 例：3 点护甲挡 1 点穿刺伤害，精确消耗 0.5，余额 2.5。
- **取整对象是护甲余额**，不重新倒算已挡住的原伤害；玩家向下取整（留 2），敌人向上取整（留 3）。

### 3.4 生命力与超杀

- 负生命示例：−5 → −2；0 点受到 4 点伤害到 −4。
- **超杀**条件：最终负生命超过生命上限（hp < −hpMax）即死；本项标记为**待校核**（F34）。
- **毅力**：比较护甲等减免**之后**的伤害（例值 15 而非原 25），可依条件将生命保在 1（F44）。
- 负生命再受生命层伤害：保持 HP 并死亡标记 +1，不继续扣负血。
- **「失去生命值」**（剪影、抽血等）：**跳过防御层**（护盾/护甲/临时生命/抗性），但**仍触发「受到伤害」相关效果**（唤醒魅惑、解除冻结等）（D102）。
- **毅力**（帮助页关键词规则·效果标签）：当目标生命值降至 0 或以下时，若这次伤害值不超过对方最大生命值，则将目标生命值降至 1。

## 8. 伤害类型与抗性口径

- 同一次攻击的**类型成分**与**独立攻击段**必须分开：同次先合并再处理抗性；二连斩等独立攻击分别命中、分别扣抗性。
- 护甲值对不同类型的倍率见 §3.1。
- 抗性／易伤按伤害类型逐项计算；护甲余额取整见 §3.3。
