## 8. 关键词筛选系统

### 8.1 实现原理

每个职业的筛选逻辑通过 **IIFE（立即执行函数表达式）** 包裹，隔离变量作用域，避免多个职业之间的命名冲突。

`javascript
(function() {
    var w_filterBar = document.querySelector("#view-warrior #w-filter-bar");
    var w_activeFilters = new Set();
    // ...
})();
`

### 8.2 筛选逻辑

- **OR 逻辑**：选中多个关键词时，技能只需包含**任一**关键词即显示
- **视图隔离**：通过向上遍历 DOM 检查 parent.id 确保只在当前职业视图内触发
- **chip 过滤**：跳过内容包含"风格"或"天赋树"的 chip（它们是标题标签，非可点击关键词）
- **目录联动**：筛选时同步隐藏导航中无匹配的链接，展开有匹配的目录分组
- **搜索独立**：搜索和关键词筛选使用不同的 CSS 类（.hidden vs .filter-hidden），可同时生效

### 8.3 筛选栏

筛选栏（ilter-bar）初始为空，由 JS 动态填充。每个已选关键词生成一个 ilter-tag，包含 × 移除按钮。

## 9. 搜索功能

### 9.1 搜索范围

搜索基于技能卡片的 data-search 属性，包含：技能名称、风格、位阶、关键词、前置条件等所有可搜索信息。

### 9.2 搜索行为

- 支持**多关键词**搜索（空格分隔），所有关键词都必须匹配（AND 逻辑）
- 搜索时使用 .hidden 类隐藏不匹配的技能
- 搜索时**保留关键词筛选**状态，两者叠加生效
- 搜索时同步更新**导航目录**，隐藏不匹配的链接
- 匹配结果中的关键词以 <span class="search-highlight"> 形式高亮并闪烁

## 10. 移动端适配

### 10.1 断点

| 断点 | 适配内容 |
|------|---------|
| ≤860px | 平板适配：单列布局、调整间距 |
| ≤600px | 手机适配：浮动按钮、抽屉导航 |
| ≤480px | 小屏手机：更紧凑的间距和字号 |

### 10.2 关键实现

- **浮动 ☰ 按钮**：固定定位在右下角，z-index: 200
- **抽屉式导航**：左侧滑出，85% 宽度，带遮罩层
- **遮罩层**：隐藏时 pointer-events: none，显示时 pointer-events: auto
- **脚本加载顺序**：JS 必须放在所有脚本之后，确保 showView 已定义

## 11. 关键注意事项

### 11.1 JS 变量名冲突

- 每个职业的筛选脚本必须在 IIFE 中包裹
- 变量名使用唯一前缀（w_filterBar、w_activeFilters）
- 使用 ar 而非 const/let 避免全局重复声明错误
- 点击处理器使用 classList.contains("chip") + 手动 DOM 遍历，避免 closest() 后代选择器冲突
- **v1.03+ 独立 HTML 上下文**：从 v1.03 起每个职业使用独立 HTML 文件，不再担心跨职业变量冲突；但每个页面内的脚本仍应使用 IIFE 包裹，避免全局污染
- **进阶页搜索高亮机制**：进阶页面使用 `oldHL` / `search-highlight` 机制（详见 `职业页/common.js`）

（自 WORKFLOW_SUMMARY.md 合并）

### 11.2 事件绑定

- 使用**直接绑定**在每个 chip 元素上
- 避免使用文档级事件委托（容易与其他事件处理器冲突）
- 事件处理器中须检查视图归属（while(parent) 遍历检查 parent.id）

### 11.3 筛选与搜索的关系

- 关键词筛选使用 ilter-hidden 类，搜索使用 hidden 类
- 两者可以同时生效，技能同时满足两类条件时显示
- 清除搜索时需同时清除导航侧栏的 hidden 状态
- 清除关键词筛选时需同时清除所有元素的 ilter-hidden 状态

### 11.4 HTML 结构完整性

每个职业页面必须包含以下元素：

- #{前缀}-filter-bar — 关键词标签展示区域
- #{前缀}-search — 搜索输入框
- #{前缀}-empty — 无匹配内容提示
- 每个技能要有 <div class="chips"> 包含 <span class="chip kw-chip" data-kw="...">关键词</span>

### 11.5 费用渲染

- 费用行不能独立成技能，必须合并到所属技能中
- 费用颜色从 docx 的字体颜色提取，使用 <span style="font-size:1.5em;color:#FF0000">●</span> 格式
- 对于浅色费用圆圈（如白色、浅蓝），需添加 	ext-shadow 描边确保可见性

### 11.6 Script 标签规范

- 不能有 BOM 字符（\uFEFF）在 <script> 标签内
- 不能有空的 <script> 标签或多余的不闭合标签
- 每个 JS 块要确保花括号和括号平衡
