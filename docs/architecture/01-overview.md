## 1. 项目概述

本项目是一个 **桌面端 + 移动端适配的 RPG 职业技能索引系统**，将所有职业的天赋技能数据从 Microsoft Word 文档（.docx）中提取，转换为一个独立的、可离线使用的 HTML 文件。

### 1.1 核心功能

- **职业切换**：首页显示所有职业卡片，点击进入对应职业视图
- **技能浏览**：按风格（流派）和天赋树阶位分组的层级导航
- **关键词筛选**：点击技能卡片上的关键词芯片，按"或"逻辑筛选技能
- **全文搜索**：支持多关键词搜索，匹配技能名称、关键词、描述正文等
- **导航目录**：侧栏显示层级目录，筛选时自动展开/收起
- **文本高亮**：搜索匹配的关键词在页面中以闪烁动画高亮显示
- **移动端适配**：抽屉式导航、浮动按钮、响应式布局

## 2. 数据源与格式

### 2.1 docx 源文件

每个职业的原始数据存储在 .docx 文件中，文件名格式为 基础职业-{职业名}（争锋模式）.docx。

### 2.2 docx 内部结构

docx 本质是一个 ZIP 压缩包，其中 word/document.xml 包含所有文本内容。文本通过 XML 标签 <w:t> 存储，每个文本片段可能被分割成多个 <w:t> 节点。

docx 文档使用 ----- 作为段落分隔符。典型的文档结构如下：

`
职业名
职责定位：...
描述文字...
-----
生命值加成
首级生命值：...
升级生命值：...
-----
疲劳值加成
...
-----
熟练项
...
-----
装备
...
-----
[起始技能1/风格名]
施展时间：...
关键词：A.B.C
费用：●（颜色标记）
描述：...
-----
一阶天赋树
[技能名称]
前置条件：...
...
-----
二~六阶天赋树
...
`

### 2.3 关键字段说明

| 字段 | 说明 |
|------|------|
| 风格（Style） | 技能的大分类，如"塑能风格"、"斗争风格" |
| 天赋树/位阶（Tier） | 一阶~六阶，技能的等级分类 |
| 技能（Skill） | 具体能力，包含前置条件、关键词、费用等 |
| 关键词 | 如"法术"、"战技"、"近战攻击"，用 . 分隔，用于筛选 |
| 费用 | 技能点 ●，不同颜色代表不同类型（从 docx 字体颜色提取） |
