# 自动引导与顾问提示开关修复记录

2026-10-03。本记录基于 v1.0.8040 工作区的修复与验收；提示开关已纳入 v1.0.8041 发布准备，线上状态以正式 Release 为准。

启动台右上角新增“提示设置”，设置页也有同样两个开关：

- 自动新手引导：默认开启，每个场景仅自动展示一次；关闭后启动台、创建页与选择页均保持安静。
- 顾问自动提示：默认关闭；控制随机小贴士和建卡主动建议，顾问入口、手动问答与主动查看建卡建议继续可用。

## 持久化与迁移

桌面端通过受限 IPC 将偏好保存到 userData/snowd-settings.json 的 promptPreferences 字段，采用 fsync、临时文件和原子替换。统一读写保留自动更新、兼容渲染及未知扩展字段，避免几个设置入口覆盖彼此。

网页和 Android 前端使用 _snowd_prompt_preferences_v1，广播更新，并在浏览器返回缓存恢复时重新读取。旧引导的完成、跳过记录迁移；记录键与应用版本无关。读取失败暂停自动提示，保存失败明确说明本次选择没有持久保存，不冒充永久关闭。

所有提示消费者等待初始偏好读取完成。桌面主窗口与真实子窗口实时同步。关闭引导会清理自动引导；手动重看只影响当前次，不重置全局开关和其他场景。

引导在首次成功展示前持久记录 shown，避免直接关闭应用后下次重复弹。加入运行中保护，延迟 700ms 的自动入口不重置正在播放的步骤。CLI 隐藏建卡页面不改变引导状态。

## 顾问行为

关闭时清理首轮、轮播、隐藏与建卡延迟计时器，不发起新自动建议请求。已有自动请求通过代次检查阻止迟到回调重新冒泡。现有传输没有取消接口，因此已发出的请求可以完成，但不能恢复自动气泡。

随机提示的实际显示间隔由共享偏好层控制，桌面由主进程原子认领，网页使用可用的 Web Locks。每次轮播都重新检查，不能靠页面初始化时的一次判断。

手动建卡建议入口位于顾问面板。流式请求增加关联标识，自动请求与手动问答同时存在时不会混入彼此的增量。

定向修正了创建页快照的职业变量引用：CHAR.className；此前错误引用 char.className 导致无法正常获得职业。

## 修改范围

新增 electron-app/desktop-settings.js、斯诺德跑团/user_preferences.js、prompt_controls.js 和 verify_prompt_preferences.cjs。接入 main/preload、引导、桌面与移动顾问、启动台与设置页，以及相关页面的偏好加载顺序。移动包与 OSS 自动注入同步使用偏好模块；Electron 镜像同步。

工作区有同时进行的角色解析重构。保留该部分源文件，在桌面壳中同步它们需要的新模块，不回退、不修改其选表规则。

## 使用和复测

从启动台右上角“提示设置”取消勾选即可。保存确认后，正常重启、切页和升级保留；清除应用数据或换到新的用户目录属于新环境。

复测命令：

~~~text
node verify_prompt_preferences.cjs
node verify_desktop_startup.cjs
node verify_ui_8003_e2e.mjs
node verify_all.mjs
~~~

通过 SNODE_PACKAGED_EXE 指向验收包的实际 exe，可以复验打包入口。本地验收包和本轮修改前备份按仓库规范归档；没有发布新版本或覆盖玩家目录。
