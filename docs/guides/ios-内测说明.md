## iOS 使用说明（A 方案：直接网页）

> 2026-11-20 调整：**不要求、也不提示安装**。iPhone 用户直接用 Safari 打开即可；
> 想去掉地址栏的用户可自行「添加到主屏幕」，不装也完全正常使用。

## 保留的增强（无需用户操作）

| 项 | 效果 |
| --- | --- |
| manifest + 图标 | 用户自愿添加到主屏幕时，图标与名称正确 |
| apple-mobile-web-app-capable | 自愿安装后全屏、无地址栏 |
| theme-color / viewport-fit | 状态栏配色、刘海安全区 |
| iOS CSS（14 行） | 固定元素避让手势条、输入框不自动放大 |

## 已移除（避免风险）

- Service Worker 与更新提示：防止缓存旧 JS；安卓 WebView 的 OTA 更新不再受影响；
- 安装引导页与站内提示：不再要求用户多一步。

## 用户需要知道的限制

1. iOS 对网页存储约 5MB，多角色可能写满 → **定期导出备份**；
2. 长期不访问的网页数据可能被系统清理 → 重要存档务必导出；
3. 离线不可用（未启用 SW）；
4. 推送、后台、文件系统能力不支持。
