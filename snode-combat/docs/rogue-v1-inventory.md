# 游荡者 v1 能力盘点

> 数据源：`职业页/数据/游荡者.json`（85 条）

## 分类口径

- `P0`：首个垂直切片，先做到可完整战斗。
- `P1`：游荡者 v1 的完整目标，P0 跑通后补齐。
- `P1*`：P1 实现，但个别子效果（如重伤/恶性创伤）暂缓。
- `P2`：需要专项系统，v1 之后再排期。
- `X`：非战斗/制作/潜行/缺描述，v1 不进入自动战斗。
