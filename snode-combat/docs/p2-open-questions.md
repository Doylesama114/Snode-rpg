# P2 游荡者技能 — 总体审视与待裁决问题

> 状态：等待项目所有者裁决。裁决后回填 `rule-decisions.md`，再进入实现。

## 一、总体审视结论

当前基线：P0/P1 共 27 张能力卡已完成，14 个测试文件 / 83 测试通过，类型检查与构建通过。
P2 共 19 张卡：闷棍、影袭、示敌以弱、暗影之刃、挑衅对决、伺机待发、蝶舞、暗里藏刀、
嫁祸诀窍、幻影匕首、飘忽不定、旋刃魂曲、剑炮齐奏、毒性蔓延、死亡印记、连击循环、
冷血杀手、剪影、无处可逃。

P2 不是单张卡工作量，而是需要先补齐这些基础系统：
1. 回合阶段机：`回合开始 / 回合结束 / 轮次结束 / 进入区域` 事件；状态卡的 DoT 与持续时间。
2. 战斗前准备：开战前用毒、暗影之刃附魔。
3. 潜行 / 视线 / 不可被选定。
4. 专注 / 引导 / 激活（唯一性已有基础）。
5. 召唤物与物件（幻影匕首、剪影）。
6. 持续伤害区域（旋刃魂曲）。
7. 交涉 / 仇恨 / 怪物 AI 改目标（嫁祸诀窍、挑衅对决）。
8. 落单 / 处决标记 / 击杀补给（暗里藏刀、无处可逃、死亡印记、冷血杀手、连击循环）。
9. 近远交替增益（剑炮齐奏）与毒系强化（毒性蔓延）。

已从 `斯诺德跑团/help.html` 和 `status_conditions.json` 核对、不再提问的规则：
- 优势 = 2 骰取高；劣势 = 2 骰取低；极大优势/劣势 = 3 骰；绝对 = 4 骰。
- 反应动作每场战斗每角色至多 3 次。
- 专注：进入惑控/失能或执行另一项专注效果时中断；受伤本身不中断。
- 引导：必须通过多个动作维持；移动或执行其他动作立即中断。
- 第一行动：必须为本回合第一个动作才能使用。
- 处决技：这次攻击的理论最大伤害能击杀目标时，忽略反制手段直接消灭。
- 魅惑状态：跳过下一个自身回合，改为在回合开始时朝施展来源做一次基础移动（由施展来源操作），
  期间无法执行反应；受到伤害或刺激解除。
- 潜行：视觉层面隐身；相邻位置有敌人时不能进入；攻击或全速移动等剧烈行动会解除；
  未识破潜行的角色途经/停留时视为该格未占据。
- 落单的既有参考定义：自身周围 6 米内没有其他友方单位。

## 二、待裁决问题（每项均给出推荐默认，可回复“全按默认”或逐条改）

### A. 阶段机 / 状态 / 持续时间

A1. 是否启用完整回合阶段机，并把状态卡里已经写好的灼烧/中毒/流血 DoT 真正接入？
这会改变 P1 已有技能的战斗数值（例如中毒每轮开始先按层数造成剧毒伤害、再 D3 追加层数）。
【默认】启用官方规则，P1 数值变化接受。

A2. “持续 N 轮”的计时口径？
【默认】以施展者自身回合计：1 轮 = 到施展者下一个自身回合开始时结束；
2 轮 = 到施展者再下一个自身回合开始时结束。
（P1 的“目标回合结束移除临时毒药状态”仍保留。）

A3. 是否新增“开战前准备”界面：可在进入遭遇前涂毒、施放暗影之刃（2分钟）等非战斗法术？
【默认】新增；消耗 FP，效果持续本场战斗；不模拟 1 小时真实游戏时钟，暗影之刃视为“本次战斗有效”。

A4. P2 卡的前置/额外条件（剧情向）是否继续沿用 P1 口径：卡在牌池里就视为可用，不做剧情校验？
【默认】是。

### B. 潜行 / 视线 / 闷棍

B1. 是否把原本分类为 X 的基础卡 `潜行` 纳入 P2 实现，作为影袭/闷棍的前置状态？
【默认】纳入：1动作、自身、1FP；相邻无敌方单位时可进入；攻击或全速移动解除；基础移动不解除。

B2. PVE 中怪物如何“识破”潜行？
【默认】v1 采用简化：潜行中的玩家不可被怪物单体攻击/单体能力选定，范围攻击仍可命中；
怪物若没有合法单体目标则结束回合，不追踪“最后已知位置”。潜行本身不额外给通用命中优势
（影袭/闷棍的卡面效果单独结算）。

B3. `飘忽不定` 中“对方必须花费动作进行一次瞄准行动，检定失败将无法选择你作为目标”具体如何结算？
卡片未写 DC 和属性。请指定，候选：
(a) 怪物消耗主要动作做 DC15 感知检定，成功则可选你为目标直到其回合结束；
(b) 怪物消耗主要动作对你做一次无伤害的攻击命中检定，命中即算“瞄准成功”；
(c) 其他规则。
【默认】暂不实现飘忽不定的瞄准条款，等本问裁决后再做。

B4. `影袭` “命中检定时忽视目标一半的防御等级”：如何取整？
【默认】有效 AC = 目标 AC - floor(目标 AC / 2)，即 AC 15 → 8、AC 14 → 7。
伤害后 +4/+8/+12 按既有“结算后”规则；影袭释放后潜行解除。

B5. `闷棍` 的“昏迷状态”用哪套规则？
【默认】新建 `昏迷` 状态卡，按闷棍卡面执行：跳过自身回合、无法执行任何动作；
持续 1D3 轮；受到任意伤害立即解除；“刺激”在引擎中简化为任意伤害（不模拟巨响/搬动）。
（不套用帮助页“昏睡”的每轮开始体质豁免，因为卡面未写。）
另外怪物卡新增 `creatureType` 字段，体型序 small < medium < large < huge < …，
玩家按 medium：超过两个规格 = huge 及以上；哥布林=类人、狼=野兽、强盗=类人。
【默认】同意以上全部。

### C. 专注 / 引导 / 区域 / 召唤

C1. 专注与引导按帮助页规则实现；引导期间“执行其他动作立即中断”是否包括附赠动作和反应动作？
【默认】包括：引导维持轮中，施展者只能消耗对应动作维持，不能移动、不能使用附赠/反应；
不主动打断时由进入惑控/失能、另一专注等既有规则中断。

C2. `蝶舞` 的 2 轮引导怎么计数？
【默认】施放回合算第 1 轮；下一个自身回合消耗 1 个主要动作完成第 2 轮，
该自身回合结束时（即引导效果结束时）结算第二次魅力豁免与心灵伤害。
首次施放时所有 6 米内敌方角色各做 DC15 魅力豁免，失败进入魅惑。

C3. `蝶舞` “拥有魅力豁免值的角色自动视为豁免成功”在怪物卡上如何表达？
请指定：是否给怪物新增“豁免熟练/豁免值”字段？哥布林/狼/强盗是否拥有魅力豁免值？
【默认】怪物新增 `saveProfs`；三只现有怪物都没有魅力豁免熟练，因此没有自动成功。

C4. `蝶舞` L8 连击点追加伤害：如何分配？
【默认】引导成功后，可消耗任意数量连击点；每个“最终豁免失败的角色”额外受到
“消耗点数 × 1D4”点心灵伤害；L12 后该部分改为 1D6。
（2D4 基础心灵伤害是否也随 L12 改为 2D6？请一并确认。）

C5. `旋刃魂曲` 区域规则：
【默认】3×3 = 以指定格为中心、含周围 8 格的正方形，中心格必须在 12 米内且可见；
施放瞬间视为区域内敌人“进入”，立刻结算一次；之后每次移动进入（按一次移动行动计，不按经过的格数计）
和每个全局轮次结束阶段各结算一次；DC15 敏捷豁免，失败全伤、成功半伤；玩家与怪物均会被区域伤害；
L15 花费附赠动作把整片 3×3 区域朝任意 8 方向平移 3 米，新覆盖格触发“进入”，离开原格不额外结算。
是否如此？

C6. `幻影匕首` 触发模型：
【默认】匕首跟随玩家，不占用格子也不可被敌方攻击；玩家每次对“单个角色”发起攻击
（基础攻击或单目标技能，无论命中与否）后，匕首立即对同一目标进行一次攻击：
D20 + 玩家当前近战攻击命中加值，命中造成 1D4 + 关键属性点灵能伤害；
匕首自己的攻击计入“三次攻击”；AOE/多目标攻击不触发匕首。
L5/L10 的飞行指令在匕首完成第 3 次攻击后，由玩家免费选择执行一次（不再另耗动作）。
“承受奥术/心灵/力场/灵能伤害后消散”暂简化为：持续时间到、专注中断或玩家主动激活结束。
是否同意？若不同意，请给匕首的“可被攻击/消散”规则。

C7. `剪影` 模型：
【默认】影子召唤在目标相邻空格，目标移动时影子不跟随；双方距离 ≥6 米或目标花附赠动作触及则解除；
玩家对影子发动基础近战攻击时自动命中：不投 D20、无暴击/大失败，不触发毒药/背刺等攻击特效，
按武器伤害公式正常结算，最终伤害的 50%（向下取整）作为生命流失直接从目标 HP 扣除（不吃抗性）；
攻击影子不获得连击点。L8 解除时目标额外 1D8 暗影伤害；L15 比例 100%。
是否同意？

D2. `嫁祸诀窍` 生效频率：

### E. 落单 / 处决 / 补给

E1. `落单` 判定：
【默认】自身周围 6 米（按现有 `combatDistance`：横向+纵向+高度）内没有其他“同阵营且存活”
单位；友方召唤物/物件算友方单位；倒地但未死亡的单位仍算友方；死亡单位不算。
`无处可逃` 施加“落单”标记时无视上述判定，持续 2 轮直接视为落单。

E2. `死亡印记` 处决规则（关键，必须指定）：
【默认 A】对带印记目标使用含“终结技”关键词的技能时照常结算命中/伤害；
结算完成后若目标仍存活，且该技能的面板理论最大伤害
（所有伤害骰取最大、所有固定加值全算、按当前连击点计算重复次数、不叠暴击、不扣抗性）
≥ 目标当前 HP，则目标被直接处决（无视毅力/反应等反制，不再重复扣血）。
适用技能：割裂、刺骨、袖箭风暴、剑刃乱舞、重磅一击。
请确认，或改选：
B：终结技只要命中带印记目标就直接处决（不做理论值比较）；
C：终结技自动按“骰取最大、命中必成、豁免必败”模拟结算，模拟伤害足够才处决；
D：其他。

E3. `冷血杀手`：
【默认】“单体近战攻击”= 带近战攻击关键词的单目标技能和近战基础攻击；
结算伤害后若目标当前 HP 为 1~4（即低于 5），直接降至 0；
“每击杀一名角色获得 1 连击点”对所有击杀来源生效（含区域/毒/处决）。

E4. `暗里藏刀`：
【默认】处于落单状态时，第一次近战攻击尝试即消耗本场一次效果（即使未命中），

E5. `连击循环`：

### F. 剑炮齐奏 / 毒性蔓延 / 伤害优势
